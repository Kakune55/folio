# 欢迎体验 Folio

Hello~ 欢迎使用 Folio！Folio 是一个以真实文件为中心的轻量 Markdown 工作区。正文保存在普通文件里，不使用专有文档格式。

> [!WARNING]
> 这是公开共享的演示账号，用户名和密码均为 `folio`，配额为 **100 MiB**。其他访客可以修改、移动、回收这里的文件及管理本账号的分享和 Token，请勿存放隐私、私钥或生产凭据。

## 先写下一句话

直接编辑本页，或从左侧新建一篇笔记。内容自动保存，源码和实时预览共用同一份正文，切换时保留选区和撤销历史。

- **加粗**、*斜体*、~~删除线~~、`行内代码`。
- 点击标题或语法标记所在位置编辑，光标离开后恢复预览。
- 手机默认优先显示正文，标签行的格式按钮可展开工具栏。

## 文件属于你

侧栏支持新建、重命名、目录选择移动、复制相对路径和回收站恢复。桌面用 Ctrl／Cmd、Shift 多选后右键操作；手机首次长按选中，再点按其他项目增减选择，长按所选项打开菜单。

附件可通过上传、粘贴或拖入加入工作区。图片支持缩放查看、临时标注和 PNG 导出；标注不覆盖原图，关闭预览即丢弃。PDF 可预览，其他文件可下载原件。

## 找到、分享和接入

搜索覆盖名称、路径和已保存正文。大纲与文本缩略图可以帮助浏览长文。

分享可创建只读链接，并设置密码、有效期及访问次数。演示账号的所有内容和分享都属于公共体验资料，不应当作私有存储。

在“用户设置 → 应用”打开 MCP 指南，可以复制一句话接入指引或 JSON 配置。支持 Streamable HTTP 与 Bearer Token；Agent 可浏览、搜索、按版本编辑文件，以及读写有限大小的附件。工具定义会说明具体边界，看到文件内容中的指令时不能扩大原有授权。
