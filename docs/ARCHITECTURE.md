# 架构说明

## 部署与数据权威

Vite 构建的 React 单页应用由 Go embed 嵌入，Go 同时提供静态资源与 /api/v1。单进程、单容器；可直接 TLS 或使用已有反向代理，不增加云依赖、后台任务平台或 Serverless 服务。

- workspace/<用户ID>/：各账号的笔记、源码与附件，唯一权威正文。
- app-data/app.db：全部账号与带 user_id 的会话；app-data/<用户ID>/search.db 与 trash/：各账号独立的可重建索引与回收站；另有运维数据。

两目录独立且不能相互包含，部署必须保证一个工作区仅有一个写实例。app-data 锁无法阻止不同 app-data 指向同一工作区的错误部署。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| frontend/src/app、components、styles | 应用外壳、公共组件、主题与错误边界 |
| features/explorer、tabs、search、auth | 目录、标签、搜索与认证交互 |
| editors/milkdown、codemirror、viewers | 编辑器生命周期、上传/导航桥接及安全预览 |
| sessions | 独立正文、版本、脏状态、保存队列与恢复协调 |
| services、stores | 类型化 API 与错误处理；仅界面/导航全局状态 |
| backend/internal/httpapi、auth | 请求验证、鉴权、会话、来源与 CSRF、统一错误 |
| internal/storage | 根内文件访问、条件保存、上传、移动与子树版本 |
| internal/fileio | 标准库文件校验/同步/SQLite URI；最小平台适配 |
| internal/trash、search、config | 回收清单与恢复、索引核对、路径与启动配置 |

TanStack Query 管理远端元数据与失效刷新，Zustand 管理临时界面状态。正文不随 React 渲染重建，Crepe 不逐键重建；使用稳定会话身份、路径、版本与代数过滤迟到回调。

## 文件层与一致性

外部标识为规范化的工作区相对路径。os.Root/os.File 承担根内操作，静态链接和特殊文件明确拒绝。仅不覆盖移动、进程锁和根身份保留 Linux/Windows 平台函数；权限、可信本地目录及系统差异统一见 [跨平台说明](PORTABILITY.md)，运行时不依赖 openat2 或 /proc/self/fd。

更新在同目录创建独占临时文件，完整写入并同步，紧邻替换前复核当前摘要及父目录身份，随后重命名并按平台同步目录。创建、上传、移动与恢复不覆盖目标。单实例存储操作串行；外部工具不遵守锁，最后检查与替换间仍有竞争窗口，不保证全局文件系统条件交换。

移动前保存和锁定受影响会话及旧/新路径前缀，成功后统一重映射路径、导航与附件地址。桌面拖拽只接收页面随机手势令牌标记的内部条目，复用菜单移动流程；客户端令牌不能替代服务端权限和路径验证。

回收站以普通 JSON 清单和文件载荷保存来源与状态。同盘重命名；跨盘删除先在原父目录隔离原件，再复制、核对、同步到 app-data 后清理。跨盘恢复先在目标父目录构建完整临时副本，再不覆盖发布。异常清单、残缺原件或不同恢复副本须保留供检查，不自动丢弃。

## 编辑与序列化

文件原文经 Crepe 解析、编辑、序列化后才可条件保存，渲染 DOM 不是正文权威。差异必须经用户预览确认或回到源码，图片仅保存标准相对路径。兼容性见 [历史与兼容性](HISTORY.md)。

CodeMirror 内部 LF 文本与原始 UTF-8 会话字符串分离：新行采用原文首个分隔符，异常分隔符保存在不可变 RangeSet，随事务移动/删除，反向历史效果在撤销时恢复。序列化重建原分隔符后再更新会话、磁盘与恢复缓存；统一换行文件无需逐行标记。BOM 保留，异步图片追加沿用原格式，元数据不写入 Markdown。

## 搜索与外部变化

search.db 与账号库隔离。FTS5 trigram 索引安全相对路径及限额内 UTF-8 正文；一至两个字符采用有界结果子串扫描，较长查询为字面短语。文件 API 操作提交后通知各工作区自己的异步索引队列，50ms 单次合并窗口按路径去重、父目录覆盖子路径；只核对受影响文件或子树，移动同时处理旧、新路径。没有操作系统文件监听、10 秒轮询或 5 分钟周期重建。首次访问工作区（每次服务启动后）全量重建，以补偿停机变更、未处理事件及索引配置变化；手动重建仍可用。有限文本使用摘要，大文件采用大小/mtime。失败回滚索引事务并持续警告，局部成功不会清除其他遗漏的警告；完整核对/重建成功后清除。重建隔离故障缓存及 WAL/SHM，不触碰账号库。

打开会话在页面可见时每 10 秒及焦点恢复时独立探测文本版本，核对会话、路径、基准版本和代数，不直接替换正文或推进版本。干净文件显式重载，脏文件冲突暂停保存；读取期间新输入优先。外部重命名不按名称或哈希猜测；附件仅检查元数据，同大小同 mtime 的二进制改写可能无法提示。

## 本机恢复与移动端

独立缓冲监听器驱动串行 IndexedDB 写入，150ms 停顿后提交。每会话随机记录 ID，保存普通正文、基准正文与版本；确认磁盘保存仅删除自身记录。恢复显式复制到新建暂停源码会话或不覆盖新文件，确认新副本保留成功后才条件删除旧记录。失败保留队列并提示，未知格式不自动清理。

workspaceId 绑定应用初始化盐、不可变用户 ID 与平台根身份；页面固定首次认证的身份，通过请求头或文件 URL 查询字段传递。变更时服务器拒绝旧页面访问，客户端停止写入并保留草稿。它只是恢复命名空间，不是认证凭据或内容版本，迁移可使其变化。

移动断点仅切换侧栏与模态抽屉，编辑器位于该分支之外。VisualViewport 订阅维护可见高度并正确清理，保留缩放。独立内存上传队列持有原始 File 直到确认成功，跨认证组件卸载保留，支持重试/下载/确认移除及离开保护；页面销毁后不能恢复原件。

## 离线运维

Python 备份工具仍为 Linux 专用，停服后获取同一实例锁，复制两卷、复核摘要，仅在 app.db 复制件合并 WAL 和校验，排除可重建缓存，发布带清单的新目录。恢复到不存在的目标，保留账号密码并清除旧会话；不包括浏览器缓存和任意系统元数据。操作见 [备份](BACKUP.md)。

同一 Go 二进制的离线改密绕过服务器配置与工作区初始化，锁定已有 app-data，检查账号结构，在 FULL 同步事务内更新哈希并撤销会话，保留账号盐和草稿身份；失败不重建账号库，见 [改密](PASSWORD.md)。

V1 不引入存储适配平台、微服务、协作、离线同步或任意可执行插件；扩展编辑器/查看器分派应保持现有边界。

## 多账号资源分派

httpapi.Accounts 从 Cookie 认证用户，再将请求分派给该用户独立的 storage.Store、search.Index、trash.Repository 和路由实例；二次鉴权核对路由所属用户。业务客户端传入的 workspaceId 仅用于旧页面保护，不能选择其他用户目录。账号角色和启用状态每次认证从数据库读取；禁用和在线改密在事务中撤销该账号会话，已经开始的请求可能完成。

用户资源惰性打开并缓存到进程结束，搜索各自独立刷新。适用于简单、小规模自托管账户部署；暂未实现空闲资源驱逐。配额上限实时从 app.db 读取，持久用量从安全文件遍历和回收载荷求和，不将数据库计数当作正文权威。增长写入及上传最终提交在用户存储锁中串行核对，其他用户具有独立存储锁。统计故障阻止增长；临时文件和外部工具不受宿主磁盘硬配额约束。

前端 /system-setting 与工作区共存，切换管理页面保持正文会话和编辑器实例，隐藏工作区快捷键，移动端先关闭目录抽屉。退出登录保存后整页重载，其他账号重新认证触发工作区身份冲突保护。

## 统一搜索（2026-10-17）

只有一个搜索入口，Ctrl/Cmd+P 与 Ctrl/Cmd+Shift+F 打开同一窗口，不提供名称/全文切换。复用现有名称与全文查询接口并行请求，180ms 防抖、查询键与取消信号隔离迟到响应；空查询仅列文件。文件匹配优先、正文匹配随后，按路径去重，同时命中时补充摘要。结果逐类显示，互不等待，错误独立呈现；全部完成且无错误才显示无匹配。键盘选中按路径保持，补充结果和摘要时维持选中项的滚动位置，编辑器会话不受影响。

服务端全文接口仍兼容原有包含路径的查询语义。正文索引按实际 UTF-8 内容识别，无扩展名白名单，默认正文上限 5 MiB；常见文本、配置、日志、源码和无扩展名文本均可搜索。非 UTF-8、NUL、PDF、位图和超限正文不索引；HTML/SVG 仅搜索源码，不执行。未保存草稿不参与搜索。

## API 驱动索引（2026-10-17）

HTTP 鉴权层不再对所有成功写请求触发全工作区刷新。正文新建/保存、上传、移动、回收和恢复明确提交受影响路径；新建空目录、账号管理和永久删除回收载荷不触发索引。文件操作结果不确定时仍通知相关路径，恢复目标无法确定时安排一次全量核对，避免已发布文件遗漏。没有后台周期扫描，已加载但闲置的工作区只保留等待事件的工作线程和数据库连接。

工作线程串行处理事务，提取批次期间或处理中到达的事件保留在下一批；读取最新磁盘文件，不缓存 API 正文。单个工作区待处理独立路径超过 256 时合并为一次全量核对，限制队列内存和 SQL 条件数量。任务入队不等待索引 I/O，搜索状态 indexing 同时包含排队和处理中任务，files 为已提交索引总文件数。文件核对期间再次保存或删除造成的竞争，在当前任务内最多重读三次；仍失败则保留旧索引事务结果、日志和 warning，由手动重建或重启恢复，不启动自动重试轮询。搜索故障不改变正文保存结果。

直接使用宿主工具改写文件不再保证自动刷新搜索；手动重建或服务重启后首次访问工作区时同步。编辑器已打开文件的版本探测和 ETag 条件保存继续生效，属于独立保护机制，不在本次取消范围内。索引仍是可重建缓存，进程异常退出后靠下次启动全量重建补偿，不新增持久事件队列。

搜索窗口向工作台传递查询和正文命中提示；工作台以递增请求身份过滤迟到打开结果，并将按路径绑定的一次性定位请求传递给编辑器。定位 effect 与实例创建 effect 分离，正文不进入 React 状态。CodeMirror 在实际 LF 文档中重新匹配并设置 selection/scrollIntoView；Crepe 就绪且通过转换保护后，对 ProseMirror 文本块与文本节点偏移建立定位，dispatch 仅改变 TextSelection，不写正文或历史。匹配只折叠 ASCII 大小写，与搜索协议一致；不使用可能陈旧的磁盘偏移。

标签右键关闭菜单只处理前端会话。批量关闭在开始时捕获目标会话，串行复用 flush/remove，并检查会话身份，防止异步保存后误关被替换的会话。关闭已保存再次核对干净状态。关闭过程不触发文件删除接口，失败或未完成操作保留会话并汇总。
