# 架构说明

## 部署与数据权威

Vite 构建的 React 单页应用由 Go embed 嵌入，Go 同时提供静态资源与 /api/v1。单进程、单容器；可直接 TLS 或使用已有反向代理，不增加云依赖、后台任务平台或 Serverless 服务。

- workspace/<用户ID>/：各账号的笔记、源码与附件，唯一权威正文。
- app-data/app.db：全部账号与带 user_id 的会话；app-data/<用户ID>/search.db 与 trash/：各账号独立的可重建索引与回收站；另有运维数据。

两目录独立且不能相互包含，部署必须保证一个工作区仅有一个写实例。app-data 锁无法阻止不同 app-data 指向同一工作区的错误部署。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| frontend/src/app、components、styles | 应用外壳、公共组件、主题与错误边界 |
| features/explorer、tabs、search、auth | 目录、标签、搜索与认证交互 |
| editors/milkdown、codemirror、viewers | 编辑器生命周期、上传/导航桥接及安全预览 |
| sessions | 独立正文、版本、脏状态、保存队列与恢复协调 |
| services、stores | 类型化 API 与错误处理；仅界面/导航全局状态 |
| backend/internal/httpapi、auth | 请求验证、鉴权、会话、来源与 CSRF、统一错误 |
| internal/storage | 根内文件访问、条件保存、上传、移动与子树版本 |
| internal/fileio | 标准库文件校验/同步/SQLite URI；最小平台适配 |
| internal/trash、search、config | 回收清单与恢复、索引核对、路径与启动配置 |

TanStack Query 管理远端元数据与失效刷新，Zustand 管理临时界面状态。正文不随 React 渲染重建，Crepe 不逐键重建；使用稳定会话身份、路径、版本与代数过滤迟到回调。

## 文件层与一致性

外部标识为规范化的工作区相对路径。os.Root/os.File 承担根内操作，静态链接和特殊文件明确拒绝。仅不覆盖移动、进程锁和根身份保留 Linux/Windows 平台函数；权限与可信本地目录由部署者管理，运行时不依赖 openat2 或 /proc/self/fd。

更新在同目录创建独占临时文件，完整写入并同步，紧邻替换前复核当前摘要及父目录身份，随后重命名并按平台同步目录。创建、上传、移动与恢复不覆盖目标。单实例存储操作串行；外部工具不遵守锁，最后检查与替换间仍有竞争窗口，不保证全局文件系统条件交换。

移动前保存和锁定受影响会话及旧/新路径前缀，成功后统一重映射路径、导航与附件地址。桌面拖拽只接收页面随机手势令牌标记的内部条目，复用菜单移动流程；客户端令牌不能替代服务端权限和路径验证。

回收站以普通 JSON 清单和文件载荷保存来源与状态。同盘重命名；跨盘删除先在原父目录隔离原件，再复制、核对、同步到 app-data 后清理。跨盘恢复先在目标父目录构建完整临时副本，再不覆盖发布。异常清单、残缺原件或不同恢复副本须保留供检查，不自动丢弃。

## 编辑与序列化

文件原文经 Crepe 解析、编辑、序列化后才可条件保存，渲染 DOM 不是正文权威。差异必须经用户预览确认或回到源码，图片仅保存标准相对路径。

CodeMirror 内部 LF 文本与原始 UTF-8 会话字符串分离：新行采用原文首个分隔符，异常分隔符保存在不可变 RangeSet，随事务移动/删除，反向历史效果在撤销时恢复。序列化重建原分隔符后再更新会话、磁盘与恢复缓存；统一换行文件无需逐行标记。BOM 保留，异步图片追加沿用原格式，元数据不写入 Markdown。

## 搜索与外部变化

search.db 与账号库隔离。FTS5 trigram 索引安全相对路径及限额内 UTF-8 正文；一至两个字符采用有界结果子串扫描，较长查询为字面短语。文件 API 操作提交后通知各工作区自己的异步索引队列，50ms 单次合并窗口按路径去重、父目录覆盖子路径；只核对受影响文件或子树，移动同时处理旧、新路径。没有操作系统文件监听、10 秒轮询或 5 分钟周期重建。首次访问工作区（每次服务启动后）全量重建，以补偿停机变更、未处理事件及索引配置变化；手动重建仍可用。有限文本使用摘要，大文件采用大小/mtime。失败回滚索引事务并持续警告，局部成功不会清除其他遗漏的警告；完整核对/重建成功后清除。重建隔离故障缓存及 WAL/SHM，不触碰账号库。

打开会话在页面可见时每 10 秒及焦点恢复时独立探测文本版本，核对会话、路径、基准版本和代数，不直接替换正文或推进版本。干净文件显式重载，脏文件冲突暂停保存；读取期间新输入优先。外部重命名不按名称或哈希猜测；附件仅检查元数据，同大小同 mtime 的二进制改写可能无法提示。

## 本机恢复与移动端

独立缓冲监听器驱动串行 IndexedDB 写入，150ms 停顿后提交。每会话随机记录 ID，保存普通正文、基准正文与版本；确认磁盘保存仅删除自身记录。恢复显式复制到新建暂停源码会话或不覆盖新文件，确认新副本保留成功后才条件删除旧记录。失败保留队列并提示，未知格式不自动清理。

workspaceId 绑定应用初始化盐、不可变用户 ID 与平台根身份；页面固定首次认证的身份，通过请求头或文件 URL 查询字段传递。变更时服务器拒绝旧页面访问，客户端停止写入并保留草稿。它只是恢复命名空间，不是认证凭据或内容版本，迁移可使其变化。

移动断点仅切换侧栏与模态抽屉，编辑器位于该分支之外。VisualViewport 订阅维护可见高度并正确清理，保留缩放。独立内存上传队列持有原始 File 直到确认成功，跨认证组件卸载保留，支持重试/下载/确认移除及离开保护；页面销毁后不能恢复原件。

## 离线运维

Python 备份工具仍为 Linux 专用，停服后获取同一实例锁，复制两卷、复核摘要，仅在 app.db 复制件合并 WAL 和校验，排除可重建缓存，发布带清单的新目录。恢复到不存在的目标，保留账号密码并清除旧会话；不包括浏览器缓存和任意系统元数据。

同一 Go 二进制的离线改密绕过服务器配置与工作区初始化，锁定已有 app-data，检查账号结构，在 FULL 同步事务内更新哈希并撤销会话，保留账号盐和草稿身份；失败不重建账号库。

V1 不引入存储适配平台、微服务、协作、离线同步或任意可执行插件；扩展编辑器/查看器分派应保持现有边界。

## 多账号资源分派

httpapi.Accounts 从 Cookie 或 Access Token 认证用户，再将请求分派给该用户独立的 storage.Store、search.Index、trash.Repository 和路由实例；二次鉴权核对路由所属用户。业务客户端传入的 workspaceId 仅用于旧页面保护，不能选择其他用户目录。账号角色和启用状态每次认证从数据库读取；禁用和在线改密在事务中撤销该账号会话，已经开始的请求可能完成。

用户资源惰性打开并缓存到进程结束，搜索各自独立刷新。适用于简单、小规模自托管账户部署；暂未实现空闲资源驱逐。配额上限实时从 app.db 读取，持久用量从安全文件遍历和回收载荷求和，不将数据库计数当作正文权威。增长写入及上传最终提交在用户存储锁中串行核对，其他用户具有独立存储锁。统计故障阻止增长；临时文件和外部工具不受宿主磁盘硬配额约束。

前端 /system-setting 与工作区共存，切换管理页面保持正文会话和编辑器实例，隐藏工作区快捷键，移动端先关闭目录抽屉。退出登录保存后整页重载，其他账号重新认证触发工作区身份冲突保护。

## 统一搜索（2026-10-17）

只有一个搜索入口，Ctrl/Cmd+P 与 Ctrl/Cmd+Shift+F 打开同一窗口，不提供名称/全文切换。复用现有名称与全文查询接口并行请求，180ms 防抖、查询键与取消信号隔离迟到响应；空查询仅列文件。文件匹配优先、正文匹配随后，按路径去重，同时命中时补充摘要。结果逐类显示，互不等待，错误独立呈现；全部完成且无错误才显示无匹配。键盘选中按路径保持，补充结果和摘要时维持选中项的滚动位置，编辑器会话不受影响。

服务端全文接口仍兼容原有包含路径的查询语义。正文索引按实际 UTF-8 内容识别，无扩展名白名单，默认正文上限 5 MiB；常见文本、配置、日志、源码和无扩展名文本均可搜索。非 UTF-8、NUL、PDF、位图和超限正文不索引；HTML/SVG 仅搜索源码，不执行。未保存草稿不参与搜索。

## API 驱动索引（2026-10-17）

HTTP 鉴权层不再对所有成功写请求触发全工作区刷新。正文新建/保存、上传、移动、回收和恢复明确提交受影响路径；新建空目录、账号管理和永久删除回收载荷不触发索引。文件操作结果不确定时仍通知相关路径，恢复目标无法确定时安排一次全量核对，避免已发布文件遗漏。没有后台周期扫描，已加载但闲置的工作区只保留等待事件的工作线程和数据库连接。

工作线程串行处理事务，提取批次期间或处理中到达的事件保留在下一批；读取最新磁盘文件，不缓存 API 正文。单个工作区待处理独立路径超过 256 时合并为一次全量核对，限制队列内存和 SQL 条件数量。任务入队不等待索引 I/O，搜索状态 indexing 同时包含排队和处理中任务，files 为已提交索引总文件数。文件核对期间再次保存或删除造成的竞争，在当前任务内最多重读三次；仍失败则保留旧索引事务结果、日志和 warning，由手动重建或重启恢复，不启动自动重试轮询。搜索故障不改变正文保存结果。

直接使用宿主工具改写文件不再保证自动刷新搜索；手动重建或服务重启后首次访问工作区时同步。编辑器已打开文件的版本探测和 ETag 条件保存继续生效，属于独立保护机制，不在本次取消范围内。索引仍是可重建缓存，进程异常退出后靠下次启动全量重建补偿，不新增持久事件队列。

搜索窗口向工作台传递查询和正文命中提示；工作台以递增请求身份过滤迟到打开结果，并将按路径绑定的一次性定位请求传递给编辑器。定位 effect 与实例创建 effect 分离，正文不进入 React 状态。CodeMirror 在实际 LF 文档中重新匹配并设置 selection/scrollIntoView；Crepe 就绪且通过转换保护后，对 ProseMirror 文本块与文本节点偏移建立定位，dispatch 仅改变 TextSelection，不写正文或历史。匹配只折叠 ASCII 大小写，与搜索协议一致；不使用可能陈旧的磁盘偏移。

标签右键关闭菜单只处理前端会话。批量关闭在开始时捕获目标会话，串行复用 flush/remove，并检查会话身份，防止异步保存后误关被替换的会话。关闭已保存再次核对干净状态。关闭过程不触发文件删除接口，失败或未完成操作保留会话并汇总。


## 系统设置与状态（2026-10-17）

系统可调限制保存在 app.db 的 system_settings 单行 JSON 元数据中。启动读取持久值覆盖环境变量初始限额；损坏配置明确启动失败，不静默回退。管理员保存先校验并提交 SQLite，再更新 Accounts 配置及已打开 Store 限额；后续工作区读取新配置。Store 沿用互斥锁，索引上限使用 atomic.Int64，单次扫描快照上限；变化通知串行 worker 全量重建，运行中旧事务完成后由后续事务应用最新设置。在途上传可按开始时快照完成，下一次操作使用新设置。文件存储与账号隔离协议不变。

状态读取 runtime.ReadMemStats，指标描述为 Go 分配/保留内存而非进程 RSS 或宿主物理内存。索引文件数仅聚合已打开工作区的提交状态，不为统计打开全部账号。目录文件数/逻辑大小由独立管理员接口显式 WalkDir，跳过链接和特殊文件、支持请求取消；全局单次扫描互斥，不做周期目录扫描。Windows GetDiskFreeSpaceEx / Linux Statfs 获取目录所在卷总量和当前用户可用空间，两目录同卷时重复展示该卷数据，不能相加。其他平台明确容量不可用。

## 文档导航（2026-10-17）

editors/navigation 提供局部导航：源码使用已安装 @codemirror/lang-markdown 的解析器提取 ATX/Setext 标题及 LF 文档位置，跳过代码/注释伪标题；富文本从当前 ProseMirror 文档提取 heading 及文档位置，DOM 变更只触发延迟重新读取原生状态，不将 DOM 作为正文权威。重复标题按位置定位，不用文本搜索推断。文本缩略图基于 CodeMirror 当前文档，用 Canvas 矩形表现采样行缩进/长度，不绘制字形或遍历语法树。绘图次数约束为面板高度 / 3，每次仅取采样行前 100 字符；DPR 上限为 2。正文、尺寸或主题颜色变化才重画内容；实际可视行区间由独立 DOM 遮罩表示，滚动合并到 requestAnimationFrame，只更新遮罩位置和高度。卸载清理监听器、定时器和动画帧。开关仅为 Workbench 局部界面状态，不增加正文全局状态或 API。

缩略图拖动使用 Pointer Events 与 Pointer Capture，记录视窗内抓取偏移，每个 requestAnimationFrame 仅应用最后一个指针位置。遮罩大小和位置按真实 scrollDOM 可滚动范围计算，最小视窗高度 12px，并对轨道上下边界限位；直接设置 scrollTop，不派发正文或选区事务。pointerup、pointercancel、lostpointercapture 和卸载均清理捕获、动画帧与拖动状态。


## 个性化（2026-10-19）

顶栏快捷键前增加个性化模态框。Markdown 富文本正文宽度为 800 / 1200 / 1600px，默认 1200px，可用空间不足时收缩；小于 768px 时不应用宽度限制。编辑器字号为 14 / 16 / 18px，默认 16px，手机最小 16px；适用于富文本与源码。提供恢复默认。偏好仅保存在当前浏览器 localStorage（跨账号共用、不跨设备同步），读取/保存失败明确提示并可重新选择重试。仅通过 CSS 变量改变呈现，不重建 Crepe/CodeMirror，不修改正文、ETag 或恢复机制。手机上传入口保留在文件抽屉，极窄屏品牌缩为字标，保持顶栏操作可用。


## 彩色差异视图（2026-10-19）

components/diff 提供独立纯函数 lineDiff 与 React DiffView，精确比较包含换行符的行。先剔除相同首尾，再在 250000 单元预算内做 LCS；超限明确展示完整替换区间。组件 useMemo 按两个输入缓存计算，最多呈现 2000 行并提示限制；不进入正文缓冲或保存协议，不新增依赖和接口。


## 图片插入与引用导航（2026-10-19）

SourceEditor 在 Ctrl/Cmd+鼠标主键按下时调用 codemirror/links.ts，使用已安装 markdownLanguage 解析标准链接、图片与引用定义，不匹配代码内伪链接，不逐键解析或重建实例。富文本根捕获点击按修饰键分派，图片 node view 保留原始相对引用 data-file-link，导航仍经 resolveFileLink/openFile 与服务端鉴权。编辑器上传使用已有内存 uploadQueue，失败可下载／重试；onUploaded 仅驻留内存，重试成功向原会话追加引用，身份/锁定不符明确提示已上传路径，不重复上传已确认成功文件。


## 侧栏拖入引用（2026-10-19）

features/explorer/entry-transfer.ts 共享本页面活动拖拽条目与随机手势令牌；DataTransfer 只携带令牌，不信任外部路径。dragover 仅识别活动手势，drop 校验令牌后经 CrepeBridge.reference 检查类型与路径锁定，生成相对引用，使用原生编辑事务插入。drop/dragend/侧栏卸载清理活动手势，effectAllowed 为 copyMove，目录目标仍用 move。Milkdown 的默认 dropIndicatorPlugin 替换为保持原有 API 的生命周期包装：销毁后延迟回调不再写上下文。将既有间接依赖 prosemirror-drop-indicator 0.1.4 声明为固定直接依赖，不升级 Milkdown 或替换编辑器。


## Mermaid 代码块（2026-10-19）

milkdown/mermaid-preview.ts 提供按编辑器实例创建的预览管理器，通过 Crepe 当前版本 renderPreview 返回的 HTMLElement 占位符接入；组件会清洗并克隆节点，因此以实例 root 范围的 data-mermaid-preview 随机标识定位实际预览。MutationObserver 监听预览挂载与主题，以代码块 DOM 为身份保留已解码图片；每个块独立等待输入停顿 600ms，主题变化合并 120ms，互不重置等待时间；局部记录与版本过滤过期结果，卸载断开观察器并使异步任务失效，不进入 React 正文状态。

Mermaid 使用动态 import 本地分块，全局串行渲染队列避免 initialize/theme 的共享配置竞争；加载失败后下一次编辑可重试。输入先做长度及配置／活动资源限制，严格模式、htmlLabels=false、maxEdges=500；输出通过 data:image/svg+xml 的 img 展示，不注入活动 SVG 或绑定图内回调。图像尺寸从 viewBox 提取，临时容器按随机 ID 清理。不改变后端 CSP 或任何 API；代码选择菜单加入 mermaid 与已安装 CodeMirror 语言列表，Mermaid 代码区暂按纯文本编辑，无专用语法高亮。


Mermaid 防抖期间，Crepe 返回节点被克隆后，在 MutationObserver 阶段将同一块上次成功图片移入新占位符，避免绘制空帧；新图 decode 完成且版本仍有效才原子替换。提示行预留高度，减少正文跳动；错误保留旧图并标明上次结果。卸载／块删除使等待与队列任务失效。

## 分享与独立转存（2026-10-22）

internal/sharing 维护 app-data/shares/shares.db（FULL 同步 WAL，分享清单／口令哈希／次数／访客授权）与同目录下每账号的真实文件快照。账号库实例锁仍保证单进程写入。新分享使用 12 字节加密安全随机数经无填充 Base64URL 编码的 16 字符标识（96 位），兼容旧 48 字符十六进制标识。新建使用数据库唯一插入，ID 冲突重新生成，最多尝试 8 次且不覆盖已有记录；访客令牌、文件 ID、版本仍保持 192 位随机强度。分享持有者通过该 URL 标识定位资源，再经密码／访问资格授权；账号登录与分享授权互不替代。一个 HttpOnly、SameSite Strict Cookie 对应浏览器访客令牌，数据库以令牌 SHA-256 与分享 ID 联合绑定资格，避免每个分享新增 Cookie 造成账号 Cookie 被驱逐。数据库不保存明文访客令牌。公开路由跳过账号工作区分派，管理／转存继续按服务端登录用户分派。

分享创建／更新由服务锁串行化，管理更新携带 version，陈旧页面不能覆盖后来暂停设置。确认清单传入每文件 ETag，存储层 ReadBundle 在用户存储锁内读取、复核版本，拒绝静态链接／特殊文件和越界；总字节与文件数有界。快照在私有暂存目录准备、文件和目录同步，再不覆盖重命名发布，数据库提交后才可获取；快照读取再次验证字节摘要。启动只清理未发布的受控暂存目录，不猜测删除正式载荷。旧载荷清理失败明确报错，仍计入配额，部署者须检查应用数据；两卷都必须备份。

Store.extraUsage 纳入分享快照实际文件用量；CommitExtra 与普通保存／上传增长检查共用用户存储锁。ImportBundle 在经过验证的目标父目录下准备完整暂存目录并同步，检查父身份，再以不覆盖重命名一次发布。来源快照与转存副本均是普通文件；转存只修改副本中的根相对 Markdown URL，不经 Crepe 序列化。按原有本地信任边界，不保证恶意同用户进程和不协作外部写入者的全局条件交换。

Go 使用固定 goldmark 1.8.6 分析 CommonMark/GFM 引用并生成只读 HTML。默认禁用原始 HTML 和危险协议，图片与内链由清单重写为公开受控资源 ID，不允许任意工作区 path 参数。前端 SharedMarkdown 只接收该渲染产物，Mermaid 使用已有隔离图片预览，图片失败可重试。独立 RootPage 分派公开页面，匿名请求不会触发编辑工作区退出或采用其他账号工作区；公开页正文不进入编辑会话。

备份工具额外合并分享库已提交 WAL、完整性检查，仅操作复制件；恢复保留分享和计数并清空访客资格。旧密码离线恢复不自动删除公开分享，分享者禁用后公开读取拒绝；要撤回分享须在管理中暂停。

分享到期回收复用受锁保护的删除流程：启动、30 秒后台循环及列表读取清理，清理快照后再移除授权与记录。服务关闭先等待回收线程退出，再关闭数据库与文件根；错误保留管理记录并记录日志供重试。回收只操作到期清单的载荷路径，暂停及访问次数耗尽不触发回收。

## Access Token 与存储分类（2026-10-26）

账号库增加 access_tokens 元数据表与 user_id 索引，现有账号库以 CREATE TABLE IF NOT EXISTS 增量建立，无需清理正文或账号。凭据为 folio_ 前缀加 32 随机字节的十六进制字符串，数据库仅存 SHA-256 摘要和短展示前缀。权限、有效期和创建时工作区身份保存为元数据。

Accounts 与 protect 使用同一认证入口；出现 Authorization 头时只接受单一 Bearer 凭据，无效时不回退 Cookie。每次查库核对令牌、到期与账号启用状态，按用户分派工作区；显式方法／路径白名单授予文件、搜索、回收站权限，新增接口默认不可访问。令牌的 read/write 字段不是管理员角色，write 包含 read；移动文件进回收站和恢复同时要求 files=write 与 trash=write。令牌请求不需要浏览器 CSRF 头，Cookie 路径继续执行原来源和 CSRF 校验，不增加跨域 CORS。工作区身份变化拒绝旧令牌；不会因传入新的 X-Folio-Workspace 自动改绑。

获准请求更新最近使用时间，条件 SQL 最多每分钟实际写一次，不缓存撤销状态。改密与禁用在同一账号事务中删除会话和令牌；离线改密清除全部。备份保留摘要，恢复时清除令牌（兼容无该表的旧备份），恢复后重新申请。撤销不能中止已经开始的请求。

storage.StorageDetails 在用户存储锁内读取安全普通文件元数据，使用与配额相同的临时文件排除规则，再汇总回收载荷和分享快照。按扩展名分类，不读取正文、不触发索引刷新；取消或异常条目导致整次失败。不保证对宿主并发外部写入的快照一致性，目录较大时按需统计可能较慢。


## 应用接口契约（2026-10-26）

httpapi/openapi.json 是机器接口契约的唯一源文件，由 Go embed 暴露为 /api/v1/openapi.json，公开访问不触发 Accounts 工作区初始化。applicationRoutes 为显式令牌权限白名单，测试双向核对其与契约 operationId、权限定义的一致性；HEAD 规范化为 GET 后沿用授权，动态恢复路由只匹配一个记录 ID。

/application 经既有认证、工作区绑定和 protect 校验，仅返回当前 Bearer 的账号、令牌元数据和权限，查询不赋予新操作权。401 为 Bearer 设置 WWW-Authenticate。API 响应使用窄 ResponseWriter 包装，在 WriteHeader／Write／ReadFrom 时保留 no-store；ReadFrom 与 Unwrap 委托原 Writer，避免因标准文件服务错误清头而丢失缓存边界，不通过 GODEBUG 改全局行为。

前端 /api-docs 按需加载，从相同 JSON 渲染只读接口说明，不生成第二份端点列表、不接收令牌输入或执行文件操作。工作区仍保持挂载，设置顶栏共用 SettingsHeader。隔离应用演练脚本使用 Python 开发依赖校验 OpenAPI 与真实 JSON 响应，生产 Go／React 不新增运行依赖。


Agent 指南唯一源为 httpapi/AGENT.md，Go embed 后通过 GET /api/v1/agent.md 返回 Markdown。与 openapi.json 一样由 Accounts 直接交给公共路由，携带无效 Bearer 也不访问用户数据；服务只返回静态文本，不解析执行指南。


## 条件补丁（2026-10-26）

storage.Patch 先安全 Read 并核对基准版本，在内存中解析有界单文件 unified diff、逐行按位置匹配并形成完整候选，再复用 Store.Write 的条件提交。解析阶段不持有写锁，不发布中间块；并发变更由 Write 再次复核版本并拒绝。未修改行使用原正文与分隔符切片，BOM 独立保留；替换块新增行继承同位置删除行的非空分隔符，额外新增用首个原分隔符，无则 LF。明确验证末尾无换行标记，不将其当正文。

补丁 1 MiB、20000 操作行、256 hunk，源／结果最多 200000 行，候选字节同时受实时文本限制；有界线性解析，不调用外部程序或引入新依赖。dryRun 不写文件、不通知索引、不预留配额或版本；实际修改才触发写入和路径通知，持久化结果不确定的错误沿用已有索引补偿。多文件事务、模糊匹配、原位写盘和自动合并不在此接口范围。
