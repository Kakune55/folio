# 架构说明

本文维护模块、数据流和一致性机制；产品边界见 [SPEC](SPEC.md)，交互见 [DESIGN](DESIGN.md)，部署与恢复命令见 [README](../README.md#快速开始)。实现中的具体资源阈值以对应源码常量为准，不在多份文档重复同步。

## 进程与数据

Vite 生成的 React SPA 由 Go embed 提供，Go 同时服务 `/api/v1`。单进程、单实例写入；可直接 TLS 或使用已有反向代理，不增加 Serverless、队列平台或独立正文服务。

| 数据 | 权威性／恢复性质 |
| --- | --- |
| `workspace/<用户ID>/` | 正文、源码与附件的唯一权威 |
| `app-data/app.db` | 账号、会话、Token、系统设置，不能当缓存删除 |
| `app-data/<用户ID>/search.db` | 可从真实文件重建的独立索引 |
| `app-data/<用户ID>/trash/` | 回收清单与真实载荷，需备份 |
| `app-data/shares/` | 分享数据库、资格和真实快照，需备份 |
| IndexedDB／localStorage／内存 | 本机草稿、标签／偏好、未确认上传与通知，不属于服务器备份 |

账号目录按不可变用户 ID 分派。两数据根不能互相包含；app-data 实例锁无法防止“不同 app-data 指向同一 workspace”的错误部署。

## 模块与状态归属

| 模块 | 职责 |
| --- | --- |
| `frontend/src/app`、`components`、`styles` | 外壳、公共交互、主题、错误边界 |
| `features`、`services`、`stores` | 文件／搜索／设置交互、类型化 API、界面状态 |
| `sessions` | 独立正文、基准版本、脏状态、保存队列、外变与恢复协调 |
| `editors`、`viewers` | CodeMirror 6 生命周期、原文实时预览、导航上传桥接、安全预览 |
| `backend/internal/httpapi`、`auth` | 认证分派、请求校验、Cookie／Token、来源与 CSRF |
| `storage`、`fileio`、`trash` | 根内访问、条件提交、平台原语与恢复载荷 |
| `search`、`sharing`、`config` | 索引、受控分享与设置持久化 |

TanStack Query 管远端元数据，Zustand 管界面状态；正文不进入 React／Zustand 全局状态，不逐键重建编辑器。异步读取、初始化、上传及保存均核对会话对象、路径、版本和代数；迟到结果不能覆盖新输入。

## 文件一致性与配额

使用 `os.Root`／描述符做根内操作，拒绝静态符号链接、硬链接、特殊文件和越界路径；运行时不依赖 openat2／`/proc/self/fd`。运行用户、目录权限／ACL、挂载及恶意同用户进程属于部署信任边界。

保存先在同目录独占临时文件，完整写入并同步，紧邻替换前复核文件摘要与父身份，再重命名并按平台同步目录。创建、上传、移动和恢复不覆盖目标；Store 串行提交，强版本从正文生成。对不协作外部写入者，最后检查与替换之间仍有竞争窗口，不保证全局文件系统条件交换或跨平台相同持久性。

配额在用户存储锁中复核实际用量，正文、附件、回收载荷和分享快照共同计费；统计失败拒绝增长写。临时文件、外部写入和并发磁盘占块不等同宿主硬配额。移动前保存／锁定受影响会话，成功后重映射路径及相对引用。

回收清单记录阶段与载荷。同盘重命名；跨盘先隔离原件，再复制、校验和同步。恢复在目标父目录准备完整副本后不覆盖发布。失败保留清单、隔离原件或副本，不猜测清理；未知提交结果必须核对。

## 编辑与保源

`SourceEditor` 统一承载 Markdown 实时预览与源码编辑。CodeMirror 6 文档是原文编辑缓冲，不引入富文本文档模型；Decoration／widget 只负责显示，不从 DOM 或预览结果重序列化正文。不支持渲染的语法和未知 HTML 保留为源码文本，不执行任意 HTML。纯文本粘贴保留原始内容及换行，不把 URL 自动改写为链接；富 HTML 转换不是隐式粘贴行为。

同一文件的模式变化使用 `Compartment` 切换显示扩展，组件 key 不含模式，保留选区和撤销历史。内部 `rich`／`source` 值保留已有偏好，界面标签为“实时预览”／“源码”。换文件或真正接纳外部正文仍按 generation 重建，旧实例异步回调不能写入新代数。

[live-preview.ts](../frontend/src/editors/codemirror/live-preview.ts) 基于语法树和可见范围装饰文本；[preview-blocks.ts](../frontend/src/editors/codemirror/preview-blocks.ts) 提供图片、Mermaid 与简单表格的块预览。表格由 [table-widget.ts](../frontend/src/editors/codemirror/table-widget.ts) 在活动单元格内提供临时 CM6 编辑视图，每次输入经范围、结构及当前文档身份验证，以最小事务同步到外层原文；外层保有唯一保存缓冲与撤销历史，不从 DOM 重建表格。输入法候选沿用会话保存保护，外层撤销／重做可同步回单元格。交互与输入边界见[设计规范](DESIGN.md#保存与恢复)。解析和渲染工作有界，超预算降级显示源码，不以预览预算阻止文本编辑。

资源仍通过 [bridge.ts](../frontend/src/editors/bridge.ts) 校验与授权，不将任意 URL 或 HTML 注入预览。上传保留原件恢复链，迟到结果核对会话、路径与代数；已上传但未插入时显示路径和恢复入口，不重复上传。

[line-endings.ts](../frontend/src/editors/codemirror/line-endings.ts) 将内部 LF 文档与原始字符串分离，RangeSet 跟踪原换行，撤销恢复分隔符，保存重建 BOM／LF／CRLF／CR。事务提交前校验原始字节映射，失败明确拒绝而不全文规范化；ETag 条件写、独立草稿及恢复链不变。大纲／缩略导航和搜索定位读取原生状态，不把 DOM 当正文；显式导航优先于旧滚动恢复，不为选中或滚动重建编辑器。

输入法组合态记录在会话中：本地缓冲／恢复副本可保留候选，但自动／手动保存、远程重载和文件操作暂停，原生确认后才提交最终文本。取消候选恢复原文，不制造版本变化；确认被切页／销毁中断时独立标记暂停，旧保存响应不能解除，须明确手动确认后再写。候选期间图片上传成功只报告已上传位置，不通过追加引用重建原文或自动确认候选。预览装饰在组合期间冻结并映射位置，应用快捷键不抢占候选确认。

## 会话恢复与上传

IndexedDB 串行保存本机草稿、基准正文与版本；确认保存仅删除本会话记录。恢复先创建暂停源码会话或不覆盖副本，确认副本成功后才条件删除旧记录；失败和未知格式保留导出／确认清理入口。

workspaceId 由初始化盐、用户 ID 和平台根身份派生，用于命名空间与旧页面保护，不是认证或版本。迁移可能改变它。标签恢复只保存账号／工作区下路径与顺序，正文从服务器重读，不自动应用恢复稿。偏好不保存正文。

上传队列独立于认证组件持有原始 File，确认前可重试／下载／移除；页面销毁不能恢复原件。跨页面、断点和管理页切换保持编辑器挂载；退出和账号变化不得让迟到任务写入另一会话。

## 搜索与变更通知

每个已打开账号独立持有 Store、FTS5 trigram 索引、回收仓库及 changeHub，惰性缓存至进程结束，暂无空闲逐出。索引只存已保存文本，限额和二进制名称处理不依赖扩展名白名单。

文件 API 提交后异步合并受影响路径，移动核对旧／新前缀；队列有界，溢出全量核对，结果未知时也补偿。首次访问工作区重建以覆盖停机变更；失败保留 warning，完整核对成功才清除。没有定时扫描或系统文件监听；宿主外写需手动重建／重启。

SSE 只向同账号浏览器发送路径／reset 和可选可信名称，不传正文、版本或凭据，不持久重放；慢连接合并 reset，关闭服务终止流。客户端串行核对，重连／在线／焦点／可见时完整检查，定期版本探测兜底。SSE 与搜索异步更新独立，都不代替 ETag。

远程通知在会话层保存本轮初始正文与最新版本，只驻内存。干净会话立即加载，脏会话保留并暂停保存；接受只清通知，等待保持暂停，回滚复用条件写。探测落地时重新检查待确认通知身份，不能复活已接受轮次的回滚基准。

差异 widget／Decoration 是只读装饰，清理用 StateEffect，不改正文／选区／历史、不重建编辑器。真正接纳外部正文可能重置撤销栈，旧实例回调受代数保护。界面及生命周期规则见 [DESIGN](DESIGN.md#远程更新与差异)。

## 认证、分享与接口来源

Accounts 每次验证账号启用状态与 Cookie／Token，再分派本人资源，不能由客户端 workspaceId 选择其他用户。Bearer 方法／路径显式白名单默认拒绝新增私有路由；摘要存库，无效 Authorization 不回退 Cookie，撤销不缓存。

账号密码使用 Argon2id。Access Token、会话及访客凭据使用密码学安全随机数，Token／访客资格的完整凭据不落明文库；改密、禁用和重置在事务中撤销相关登录／令牌，已开始的请求可能完成。离线改密撤销全部账号会话／Token，不自动撤销分享；备份恢复另清访客资格并保留分享数据。备份只在复制件合并 WAL 和校验，不修改源库。

分享使用独立数据库、资格和受控资源 ID。快照在私有临时目录校验、同步、不覆盖发布后提交元数据；读取再次校验摘要。转存在接收用户存储锁下准备新目录后一次发布，只改副本相对引用，不经编辑器重序列化。到期清理受锁保护，失败保留记录；暂停／次数用尽不自动清理快照。分享 WAL、载荷和访客资格恢复属于双卷备份流程。

公开 Markdown 用固定解析器生成清洗的只读产物，资源 URL 重写为白名单 ID；活动 HTML／SVG 不执行。Mermaid 限制配置与资源、串行渲染为隔离图片，不注入活动 SVG 或执行图内回调，错误保留旧图及提示。

REST 应用 OpenAPI 是其字段与权限契约唯一来源；Agent 指南是精简启动说明，索引与单操作文档从 OpenAPI 静态派生，不读取用户资源或外部 schema。`/mcp` 使用官方 Go SDK，以请求级无状态 Streamable HTTP 适配同一存储、索引及变更通知逻辑；工具 Schema 由 Go 输入类型生成，每次请求重新验证 Bearer、工作区与现有路由权限，不跨请求保存身份。HTTP 参数层区分位置缺失与非法路径，不从 body／query 互相回退。私有浏览器及共享 HTTP 规则见 [API](API.md)，运维见 [README](../README.md#快速开始)。
