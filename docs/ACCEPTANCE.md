## 使用边界

- 文件系统最后一次版本检查与替换之间，对不协作外部程序仍存在不可当作全局 CAS 的窗口；同工作区只支持一个写实例。备份需停止外部写入者并成对处理两卷。
- 浏览器缓存存在提交窗口、配额与驱逐风险；待确认原始附件只在页面内存，不能承诺刷新/崩溃恢复。关闭/升级前确认保存或下载，旧页面刷新后才加载新构建。
- 不安全 Markdown 保持源码编辑；PDF 的字体/大图等可能不完整，原件下载始终保留。SVG/HTML 不活动预览，未知二进制不自动解释或执行。
- 真实读屏器、复杂编辑器部件的全部辅助操作、手机相机/软键盘/IME、其他浏览器、原生 ARM 硬件、实际外部反向代理和 Docker daemon 尚未在本机验证。自动扫描、AX 树与仿真不替代这些环境。
- SIGKILL/ENOSPC/备份演练不是所有文件系统的断电证明。ACL/xattr/UID/GID/稀疏文件等完整系统级恢复、嵌套挂载/链接/特殊文件不在离线工具支持范围；它们明确失败而非跳过正文。
- app-data、备份、私钥、浏览器配置和运行 UID 属于私有运维数据；不抵御恶意同 UID 程序。实际公网 TLS、来源、代理请求限制与状态码透传仍由部署者按 DEPLOY.md 核对。
