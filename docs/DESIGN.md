# 视觉与交互规范

## 视觉原则

简洁但不空洞，安静、清晰、克制，正文始终是视觉重点。借鉴 Linear 的精度、Obsidian 的布局和 Crepe 的排版，不照搬产品。不使用复杂仪表盘、强制右侧面板、巨大圆角卡片、玻璃效果、堆叠渐变、装饰插画、跳动动画。

默认使用简体中文，包括辅助名称、加载和错误提示、编辑器菜单。技术名称与代码标识符保留原样。字体使用系统已有 Inter 或 system-ui、Segoe UI、Noto Sans CJK SC 等，不嵌入或再分发字体文件。

## 主题与排版

语义 CSS 变量统一管理颜色，默认跟随系统，可持久保存手动选择。以下为初始参考，实际对比度须经验证调整：

| 变量 | 浅色 | 深色 |
| --- | --- | --- |
| --background | #FFFFFF | #202124 |
| --sidebar | #F7F7F8 | #191A1C |
| --surface-hover | #EEEEEF | #303135 |
| --border | #E7E7E9 | #35363A |
| --foreground | #202124 | #EEEEEE |
| --muted-foreground | #777B83 | #A1A1A8 |
| --accent | #5365B8 | #94A8FF |

焦点、危险操作、选择、提示、滚动条和代码区域各自定义语义变量；强调色仅用于选中、焦点和链接。明暗主题保持同等层次，对比度以 WCAG AA 为目标。

正文默认 16px、行高约 1.7，居中宽度默认 1200px（可在个性化中调整）；界面主要文字 13–14px，次要文字 12–13px；代码使用系统等宽字体 13–14px，状态数字等宽。标题清晰但不过大，代码块可内部横向滚动。

间距以 4px 为基准。侧栏默认 240px，调整参考范围 200–360px；顶栏 40–44px，标签栏 34–38px，目录行约 28–32px。边框 1px，常规圆角 6px，浮层 8–10px，仅浮层使用轻阴影。操作按钮使用 Lucide 图标 15–18px、统一描边；文件类型使用 VS Code Symbols 的原生配色小图标，统一 16px，不额外添加彩色背景。动画 120–180ms、位移 2–4px，遵循减少动态效果设置。

## 工作区布局

桌面为紧凑顶栏、左侧可折叠目录、横向标签栏、正文与克制的底部状态栏。顶栏保留工作区、搜索、主题与必要设置，不建立竞争导航。当前文件用浅底色或细指示线，脏标签用小圆点；保存状态不依靠颜色独自表达。

1024px 以上保留侧栏，768–1023px 可折叠；小于 768px 默认关闭目录，以模态抽屉打开。正文编辑器不随断点切换重建。抽屉支持遮罩、Escape、焦点约束与返回；打开文档后关闭，其他弹窗出现时交接焦点。依据可见视口与安全区安排高度，不禁止用户缩放。触控目标至少 40px，不依赖悬停，软键盘不得遮挡保存或错误入口。

## 组件行为

- 文件树：统一缩进、展开箭头和小型分类图标。操作菜单在悬停或焦点时出现，触屏保持可用。方向键、Home/End 导航，F2 重命名，Delete 确认删除，Shift+F10 操作菜单；重命名支持 Escape。桌面单条目拖到目录或根入口，显示目标、悬停展开，保留键盘/触屏移动菜单。先测量，再决定虚拟化。
- 标签栏：单行横向滚动，关闭失败保留标签与正文。tablist 只包含标签；鼠标关闭标记在标签内部，辅助技术另有标签栏外的当前标签关闭按钮，聚焦时可见。Delete 保存并关闭，焦点回到剩余标签或目录按钮。
- 编辑器：保留 Crepe 原有交互，以局部语义变量适配表格、代码、浮动工具栏、选择和两种主题。源码切换可见，模式控制为具名分组，保存状态低干扰，不为每次保存弹通知。
- 弹窗：复用现有 shadcn/ui 与 Radix，统一内边距和焦点样式，Escape 关闭并返回触发位置；包括没有 Radix Trigger 的程序打开窗口。快开聚焦组合框，方向键选结果，不让每个结果增加 Tab 停靠点。
- 转换与冲突：双栏显示本地/磁盘或转换前后源码，手机改为单栏。转换差异可展开并下载原文；初始焦点在保留原文，取消不覆盖，确认清楚说明转换、后续自动保存和撤销限制。
- 恢复稿：底栏提供入口，认证后显示本工作区缓存；比较后显式暂停恢复、下载或另存新文件。缓存成功不能标记为磁盘已保存，缓存失败须持续提示并提供操作；删除缓存需要确认。
- 上传：工具栏、菜单与拖放提供入口，图片成功后插入相对链接。大文件显示进度和失败重试。文件选择/拍照失败保留内存原件，可重试、下载或确认移除；不把它描述为持久备份。
- 空状态与错误：空工作区提供新建和上传入口，加载局部占位；保存错误固定显示并保留正文。外部变更时干净文件显式加载，脏文件停止自动保存并比较/另存；原目录缺失允许选择副本路径，失败后保留弹窗和草稿。

## 无障碍与验收

使用语义区域、可见焦点、明确辅助名称、完整键盘路径与温和的保存状态播报，避免逐键播报。编辑器支持 Escape 后 Tab/Shift+Tab 离开编辑键位；抽屉向弹窗交接时不得抢焦点。

每次界面变更检查悬停、焦点、禁用、空、加载、错误及明暗主题；在 1440×900、1024×768、390×844 检查正文主导、长文件名、宽代码块、目录滚动、上传和冲突。应用外壳不得意外横向溢出，完成界面使用真实样本文档。测试方法见 [测试计划](TESTPLAN.md)。

## 账号与系统设置

登录页提供用户名与密码；移除宣传口号和非必要说明。侧栏左下角显示用户名、账号设置入口和自适应单位的已用/配额（如 128 MB / 5 GB），管理员额外显示“系统设置”。用量读取失败保留重试入口，接近/超过额度使用文字和克制状态色提示。

/system-setting 采用简单左侧导航，包含用户管理、系统设置和系统状态；用户管理使用用户表格；提供搜索、分页、创建、编辑和独立重置密码弹窗。表格列为用户名、角色、状态、已用/配额、操作，不增加统计卡片。沿用语义主题变量、统一表单和 Radix 焦点管理。返回工作区保持标签与编辑器实例。移动端表格仅在内容容器横向滚动，不扩大应用外壳。

## 工作区细节优化（2026-10-17）

用量数字下方增加铺满侧栏可用宽度、4px 高的配额条，比例限制在 0–100%，超额使用危险状态色，保留实际数字和可访问用量说明。统计失败时不伪造比例。

底栏仅保留左侧保存状态与本机副本状态、右侧固定位置的恢复草稿入口；移除连接口号、常驻撤销提示与重复品牌/格式信息。固定栏高、保存状态宽度和恢复入口宽度，文本不换行，避免保存状态和草稿数量变化导致整排跳动。撤销历史说明放在编辑模式按钮提示中，错误与恢复入口继续可见。

文件树、标签和搜索共用 @react-symbols/icons（VS Code Symbols，MIT）文件图标，按完整文件名和扩展名自动识别；文件夹区分收起/展开，未知文件使用库默认图标，不根据图标改变编辑或预览权限。

## 统一搜索（2026-10-17）

只有一个搜索入口，Ctrl/Cmd+P 与 Ctrl/Cmd+Shift+F 打开同一窗口，不提供名称/全文切换。复用现有名称与全文查询接口并行请求，180ms 防抖、查询键与取消信号隔离迟到响应；空查询仅列文件。文件匹配优先、正文匹配随后，按路径去重，同时命中时补充摘要。结果逐类显示，互不等待，错误独立呈现；全部完成且无错误才显示无匹配。键盘选中按路径保持，补充结果和摘要时维持选中项的滚动位置，编辑器会话不受影响。

服务端全文接口仍兼容原有包含路径的查询语义。正文索引按实际 UTF-8 内容识别，无扩展名白名单，默认正文上限 1 MiB；常见文本、配置、日志、源码和无扩展名文本均可搜索。非 UTF-8、NUL、PDF、位图和超限正文不索引；HTML/SVG 仅搜索源码，不执行。未保存草稿不参与搜索。

## 当前文件信息（2026-10-17）

底栏在保存/恢复状态与浏览器恢复稿入口之间，固定宽度显示磁盘文件大小和正文索引状态，数字按 B/KB/MB 等自适应。状态包括正文已索引、仅名称索引、正文超限、索引更新中、正文未索引、索引异常；未保存时显示待保存后索引，外部版本变化时显示可能过时。超限提示中显示实际上限。点击索引状态打开统一搜索，可使用既有重建入口。查询失败明确显示状态不可用，不伪造成功。

桌面保持单行固定分区，摘要/状态文本溢出省略；手机固定两行，文件大小和索引信息放第二行，避免挤压保存与恢复入口，状态变化不改变栏高。大小始终指已保存磁盘文件，不逐键扫描编辑器缓冲。默认正文索引上限提高到 5 MiB，启动重建使现有符合条件的文本参与正文搜索。

## 源码选区与焦点（2026-10-17）

源码编辑器取消整圈焦点外框和不透明当前行底色，避免当前行覆盖 CodeMirror 在正文后方绘制的拖选背景。键盘焦点通过可见插入光标和行号颜色变化表示，工具栏等控件继续保留焦点框。深色选区使用更清晰的蓝灰色；共享代码主题的当前行背景保持透明，防止富文本代码块重现遮挡。选区修复只影响呈现，不改变正文、换行或保存行为。

Markdown 富文本同样不绘制正文整圈焦点外框，光标与控件自身焦点样式保留。富文本可编辑区域至少覆盖当前可用正文高度，末尾留白属于 ProseMirror 内部，确保段落手柄拖入末尾空白时仍可放置；不引入自定义正文重排算法。

## 搜索命中定位（2026-10-17）

从统一搜索打开结果后滚动到当前正文首次命中并选中关键词，源码与 Markdown 富文本均支持；不新增常驻说明条。仅文件名/路径命中时正常打开，无需报错。定位使用当前编辑器内容，保留草稿和现有撤销历史，重复搜索不重建编辑器。关键词因编辑已消失，或仅存在于 Markdown 标记/链接地址等不可见源码时，明确提示并保留内容，可切换源码后重搜。

## 标签页关闭菜单（2026-10-17）

标签右键或键盘 Shift+F10 使用 Radix Context Menu，沿用文件菜单的主题、间距与焦点样式，提供关闭、关闭其他、关闭右侧标签页、关闭已保存、关闭所有。没有其他/右侧/已保存目标时禁用对应项，不展示未实现的快捷键。菜单为非模态，避免遮蔽整个工作区的可访问语义。Escape 和操作结束将焦点放回当前标签，全部关闭则返回目录按钮。

批量操作固定开始时的目标集合，逐个复用条件保存与会话关闭保护；新打开的标签不被加入，失败/冲突/上传未完成的文件保留并汇总提示。关闭已保存执行前再次检查干净状态，不能顺带保存并关闭新产生的草稿。菜单不删除真实文件。


## 系统设置与状态（2026-10-17）

/system-setting 左侧提供用户管理、系统设置、系统状态；设置为紧凑的标签/数值/单位表单，状态按运行、内存、Heap/Stack、内部内存、GC 分组显示键值，不增加仪表盘卡片。运行时每 5 秒刷新，可暂停并手动重试；磁盘目录扫描仅点击统计时进行。手机导航横向排列、指标自动换行，明暗复用主题变量。


## 手机源码与底栏布局修正（2026-10-17）

手机源码编辑器水平外留白缩为 4px，行号为 12px 并缩小两侧内边距，正文内边距为 8px；行号宽度仍由 CodeMirror 按完整文档位数自适应，不裁切五位数行号。手机底栏使用固定 64px 的两行 Grid：左上保存状态、左下文件大小/索引，右侧恢复稿跨两行。取消依赖 flex 换行的百分比宽度计算，确保间距不会将恢复入口挤到第三行并裁掉索引信息。索引与恢复入口分别保留 40px/60px 点击高度。


## 手机单行底栏与行号对齐（2026-10-17）

根据实际手机反馈替代上一版两行布局：手机源码外侧水平留白为 0，正文水平内边距为 4px，行号仅保留右侧 2px；行号与正文同为 16px、1.8 行高，保留全文件位数自适应宽度，不裁切大行号。手机底栏为固定 41px 的单行：保存状态、文件大小、索引状态、恢复稿图标。恢复入口保留辅助名称、提示与非空数量，索引和恢复按钮均有 40px 点击高度。正常恢复缓存进度不常驻占用空间；缓存失败时用失败文字替代保存状态，不能隐藏故障。桌面布局不变。


手机底栏的保存状态、文件信息、恢复入口分别显式绑定网格第 1/2/3 列；没有打开文件时仍将恢复入口保留在最右侧。恢复窗口说明改为“这里显示此浏览器暂存的未保存内容，可打开检查、下载或另存为文件。清除浏览器数据会删除这些草稿。”空列表仅显示“暂无可恢复的草稿。”，不再显示无目标的选择说明。

## 右侧大纲与文本缩略图（2026-10-17）

顶栏主题和快捷键之间使用 PanelRight 图标切换右侧导航，辅助名称与按下状态表达展开/收起。桌面大纲 220px、缩略图 125px；手机分别 130px、56px，正文继续可编辑。大纲按 H1–H6 缩进，长标题省略并提供完整提示；无标题显示明确空状态。缩略图使用单色抽象短线表现采样行的缩进和长度，不绘制字体或语法高亮。超长文件按面板高度抽样，仅取采样行前 100 字符计算形状；半透明独立遮罩标示可视范围，滚动只移动遮罩。导航与正文独立滚动，切换不重建编辑器。

缩略图支持按住可视范围拖动，保留按下处的偏移，避免起手跳动；点击范围外将视窗居中定位并可继续拖动。使用 grab/grabbing 光标，触摸区域禁用浏览器默认平移；指针移出范围仍保持捕获，松手、取消或关闭面板结束手势。拖动按动画帧合并，不重新绘制内容。


## 个性化（2026-10-19）

顶栏快捷键前增加个性化模态框。Markdown 富文本正文宽度为 800 / 1200 / 1600px，默认 1200px，可用空间不足时收缩；小于 768px 时不应用宽度限制。编辑器字号为 14 / 16 / 18px，默认 16px，手机最小 16px；适用于富文本与源码。提供恢复默认。偏好仅保存在当前浏览器 localStorage（跨账号共用、不跨设备同步），读取/保存失败明确提示并可重新选择重试。仅通过 CSS 变量改变呈现，不重建 Crepe/CodeMirror，不修改正文、ETag 或恢复机制。手机上传入口保留在文件抽屉，极窄屏品牌缩为字标，保持顶栏操作可用。


## 彩色差异视图（2026-10-19）

冲突比较与富文本转换共用行差异视图：删除红底、新增绿底，明暗主题使用语义颜色；同时显示 −/+、双侧行号、增删行数和换行标记，不只依赖颜色。保留完整正文和原有确认操作，相同区域保留三行上下文，内部长相同区间折叠。差异内容以文本呈现，不执行 HTML。


## 图片插入与引用导航（2026-10-19）

编辑器链接导航统一使用 Ctrl/Cmd+点击，普通点击允许定位与编辑。富文本图片同样可用修饰键打开原文件；图片嵌套在链接中时优先打开图片。快捷键弹窗列明图片粘贴／拖入与引用打开方式。上传失败复用现有待上传原件列表，不新增弹窗或遮挡正文。


## 侧栏拖入引用（2026-10-19）

侧栏拖拽状态说明同时提示“拖到文件夹以移动，拖到 Markdown 正文以插入引用”。拖入正文使用 copy 光标，按落点插入；富文本显示图片或文字链接，源码显示标准 Markdown。没有图片扩展名的文件按文字链接处理，不改变预览安全策略。
