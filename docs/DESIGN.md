# 视觉与交互规范

本文只维护呈现与操作规则；产品能力见 [SPEC](SPEC.md)，状态和数据保护实现见 [ARCHITECTURE](ARCHITECTURE.md)，验证方法见 [TESTPLAN](TESTPLAN.md)。不记录逐次 UI 修改和测试日志。

## 视觉与主题

简洁但不空洞，正文是视觉中心。避免复杂仪表盘、装饰卡片、巨大圆角、玻璃效果、渐变和跳动动画。界面、辅助名称与错误提示用简体中文，技术名与代码标识保留原样。

统一语义 CSS 变量，默认跟随系统，可保存明暗选择；颜色实际值由 `frontend/src/styles/app.css` 维护，不另存一份色值表。选中、焦点、危险、提示及代码区域均有对应变量，明暗层次一致，以 WCAG AA 为目标，不单靠颜色表达状态。

使用系统字体，不嵌入或再分发字体；正文默认 16px、约 1.7 行高，界面主要文字 13–14px，数字等宽。代码及宽表局部横向滚动。间距以 4px 为基准，细边框、克制圆角和浮层阴影；图标尺寸统一，文件图标使用 VS Code Symbols 原生配色，不代表文件权限。

个性化调整 Markdown 宽度和编辑字号，手机保持可读字号与可用宽度；仅改变 CSS 呈现，不重建编辑器或改正文。偏好只属当前浏览器，失败明确提示，不伪装为同步成功。

## 外壳与移动布局

- 桌面为紧凑顶栏、可折叠文件树、单行横向标签、正文及稳定底栏，不建立竞争导航。
- 小于 768px 用模态目录抽屉；编辑器位于断点分支之外，不因旋转／开关抽屉重建。遮罩、Escape、焦点约束与返回完整，打开文件后关闭抽屉。
- 依据可见视口和安全区布局，不禁止缩放。操作目标至少 40px，不依赖悬停，键盘不能遮住保存／错误入口。
- 手机底栏固定单行，保存、文件大小／索引、恢复入口分区明确；空工作区仍将恢复入口置右。状态长度不能令栏高跳动或裁掉错误。
- 源码行号与正文保持字号／行高对齐，按全文件位数自适应，不裁切大行号。编辑区不画整圈焦点框，光标／选区可见；工具栏与按钮保留焦点样式。

## 导航与编辑

- 文件树有清晰缩进、展开状态及具名菜单；键盘支持方向、Home／End、F2、Delete、Shift+F10。桌面拖拽显示目标／悬停展开，仍保留键盘／触屏移动入口。
- 标签显示脏状态，关闭失败保留内容。右键菜单处理关闭其他／右侧／已保存／全部，不删除文件；固定目标集合，逐个执行保存保护，新出现草稿不能被“关闭已保存”带走。
- Ctrl/Cmd+P 与 Ctrl/Cmd+Shift+F 打开同一搜索窗口；名称结果先显示、正文补充并按路径去重，选择项和滚动保持稳定。错误独立呈现，不把加载或失败当无结果。
- 搜索命中在当前编辑器内容中定位、选中，不重建、不覆盖草稿；不可见源码或已消失关键词明确说明，不跳到猜测位置。
- Markdown 右侧为标题大纲，其他文本为抽象缩略导航；开关与正文独立，拖动视窗不重绘／改写正文。标题按位置定位，不依赖同名文本猜测。
- 链接／图片用 Ctrl/Cmd+点击打开，普通点击用于编辑；侧栏拖入正文插入引用，拖入目录移动，复制／移动光标和目标区分清楚。
- 保留 Crepe 原有工具栏与段落手柄，不自造正文重排。模式切换具名、可见，保存状态低干扰，不为每次保存弹通知。

## 保存、转换与恢复

保存、失败、本机副本分别表达；缓存成功不能显示为磁盘已保存。错误固定可见，保留重试、比较、下载及不覆盖另存入口。

转换／冲突共用彩色文本 diff，删除红底、新增绿底，保留行号／增删符号与必要上下文；不执行差异中的 HTML。桌面双栏、手机单栏，允许查看完整原文和下载；初始焦点偏向保留原文。取消不覆盖，确认说明会转换、自动保存及撤销限制。

兼容的合法排版不弹转换警告；不安全原文或粘贴明确提示源码入口，不能静默丢内容。段末 Shift+Enter 当前无法持久化时提前说明“操作未生效”，不要伪装成功；段中硬换行及正常回车保持可用。

恢复稿只在确认后打开检查、暂停恢复、下载或另存；清理需确认。提示明确说明本机草稿随浏览器数据清除而消失，不称为服务器备份。

上传失败保留原件，可重试／下载／移除；已成功上传但插入失败要显示已上传路径和恢复方式，不能重复上传。无效路径、额度及实际文件限额就地说明，不以关闭窗口隐藏错误。

## 远程更新与差异

干净的已打开文本立即显示已核对远程正文，尽量保留选区／滚动，不抢焦点；真实重载会重置撤销历史。脏正文不自动替换，也不在输入时弹冲突窗；手动保存才进入既有版本比较／副本流程。

右下角按文件显示“文件已被远程修改”、增删统计、路径与灰色小字应用来源，操作为接受（显示剩余秒数）／等待／回滚；计时规则遵循产品规范。来源未知明确标注，不把事件来源当精确版本作者。

同文件连续变更合并并重新计时；等待移除等待按钮，之后更新也保持暂停。提前接受或倒计时结束立即清除通知及其标记／详情，不重复保存。回滚成功清除，失败保留通知和恢复入口；本地输入清除失效标记但不替用户作通知决策。

修改黄条、新增绿条，删除在缺口显示红三角；源码按行、富文本按语义块。点击或键盘激活可就地展开旧／新内容，再次激活、收起或 Escape 关闭。详情红旧绿新上下无缝排列，无“替换内容”标题、无可见“修改前／修改后”标签，收起浮于右上；保留无障碍标签。

不展示图例，不开独立 Diff 弹窗；通知管理的标记与展开详情不能另按 8 秒过期或因展开延长。长内容内部滚动，截断／省略明确说明，不遮住保存入口。配额、计算和传输限制由架构／协议维护。

## 设置与分享

用户设置是账号／存储／应用导航与紧凑内容区，手机改横向导航；管理员从顶栏进入系统设置，用户名不与链接混在一起。返回工作区保留编辑器和草稿。

账号密码表单展示与服务端一致的字节规则；存储用分段条、数值和类别说明，不靠颜色猜测，失败保留重试。令牌使用资源×权限原生单选矩阵；有效期提供 1／7／14／30／90／180／365 天、永久与自定义，默认 30 天，自定义选中才显示 1–366 整数天输入与起算说明。完整凭据只在生成后显示、可复制／选择，明确“我已保存”，不写 localStorage；删除二次确认。协议取值见 [API](API.md#浏览器账号与系统接口)。

系统管理只用用户表、简洁设置表单和运行状态键值，不增加仪表盘卡片；状态可暂停刷新，磁盘统计由用户触发。手机表格只在容器内滚动，不撑宽页面。

分享管理与公开阅读独立。创建附件选择用第二层模态，主文件不可取消；确认才更新白名单，取消保留原清单。方式与限制使用原生具名控件，实时不允许附件；复制失败可手动选择。暂停／继续不额外刷成功通知，删除须确认。

分享六位密码用单个原生输入承接六格样式，数字可见、支持整段粘贴与退格，满位可验证，失败可重试。公开阅读页没有编辑或管理控件；转存必须登录，失败保留返回／核对入口，不创建本机编辑草稿。

Mermaid 复用代码块预览，编辑／预览可切换；加载和输入等待时保留上次图及提示，成功再替换，不闪空帧。错误不覆盖代码，图表有辅助名称；安全能力边界见 [SPEC](SPEC.md)。

## 无障碍检查

语义区域、辅助名称、可见焦点与完整键盘路径必备；保存状态温和播报，不逐键朗读。编辑器可用 Escape 后 Tab／Shift+Tab 离开，弹窗关闭返回触发位置，抽屉与模态交接不抢焦点。

按影响检查明暗、悬停、焦点、禁用、空、加载、错误及减少动态效果；重点覆盖桌面／平板／手机、长文件名、宽代码、软键盘与冲突。方法和执行范围见 [TESTPLAN](TESTPLAN.md)，不以 axe 单次扫描冒充完整读屏验收。
