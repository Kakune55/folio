# M2 实施记录（进行中）

## 本节点：搜索与快开

- `Ctrl/Cmd+P` 打开名称/路径快开，`Ctrl/Cmd+Shift+F` 打开全文搜索。支持方向键、回车与 Escape，打开后聚焦编辑器；中文界面兼容浅色/深色主题。`Ctrl/Cmd+B` 仅在编辑区域外折叠目录，保留编辑器加粗操作。
- 使用独立的 `app-data/search.db` 保存 FTS5 trigram 缓存，与认证 `app.db` 隔离。文件仍是唯一内容权威，损坏索引不会阻断编辑；可在搜索框请求重建。损坏缓存保存在私有 `search-recovery-*` 目录供检查，不自动清除。
- 安全遍历沿用根描述符与无符号链接策略。路径名称均可查找；符合 UTF-8、无 NUL 且未超限的文本进入正文索引，PDF/位图和其他二进制不索引正文。默认上限 1 MiB，启动变量 `FOLIO_MAX_INDEX_BYTES` 可设为 1 字节至 100 MiB。
- 应用内成功写入/上传/移动/删除/恢复异步触发扫描；外部变化每 10 秒按 inode/大小/mtime/ctime 检查，每 5 分钟完整读取核对。启动和手动重建也完整读取。扫描失败保留上一版缓存并提示可能过时；暂时不可读条目不参与索引。
- 查询是字面量子串，3 字符起使用 trigram，1–2 字符使用文本扫描以覆盖中文短词。支持 ASCII 大小写不敏感匹配；不承诺 Unicode 大小写折叠、繁简转换、拼音、词语分割或正则。默认最多 50 条，可经 API 请求至 200 条，无分页。

## 验证与边界

后端用真实 SQLite/临时文件验证中文长短词、英文标识符、路径与标点、字面量查询、重命名/删除、相同大小与 mtime 的外部改写、损坏缓存重建与编辑隔离、PDF 只索引名称及符号链接排除。浏览器验证名称快开/键盘聚焦、中英文全文搜索、浅深色界面，以及索引请求失败后正文和保存仍正常。

本节点标准回归：`make build` 成功（仍有 Crepe 大分块提示）；`make test` 通过前端 lint、6 项单元测试、15 项浏览器测试及全部 Go 测试；`cd backend && go vet ./...` 无报告。已检查本次搜索浅色/深色截图。未重跑容器双架构验收，本节点没有修改容器配方。

只查询已保存内容，结果存在刷新延迟。索引扫描不是文件系统快照，变化中的文件可能使整轮回滚，后续轮次重试。短词查询会扫描缓存正文，大工作区耗时需要 M3 实测；HTTP 查询有 3 秒截止时间，失败明确返回。索引包含正文副本，应与账号和回收站一样保护 app-data 权限；移除文件到下一次成功扫描前仍可能在旧缓存中找到它。

M2 尚未验收：目录拖拽移动、其他快捷键与整体界面复核继续按路线图推进。持久化草稿恢复、移动端和完整性能/安全/备份演练属于 M3；当前页面关闭前仍须保存或下载未保存稿件。

## 第二节点：外部文件变更协调

- 页面可见时，每 10 秒、重新聚焦/切回页面时检查已打开会话并刷新已展开的目录；手动刷新按钮也触发检查。页面隐藏时暂停，恢复可见后核对。按顺序读取，整轮 15 秒超时，失败明确提示并保留当前内容。
- 编辑文本通过 `GET /files/revision` 检查强内容哈希，与读取和条件保存的版本一致；该接口复用文本大小/类型和根路径安全约束，不递归散列目录、不返回正文。同大小、同 mtime 的改写仍可发现。
- 未修改的缓冲区保留旧正文并提示“加载磁盘版本”，仅显式加载后重置撤销历史。读取期间继续编辑会拒绝应用晚到正文。检测到变化后再输入，立即进入冲突并暂停自动保存。
- 脏缓冲区检测到外部改写、删除或移动时保留本地正文与原始版本，不推进条件保存版本。窗口可比较磁盘内容并另存副本；原目录不存在时可输入另一个仍存在的目录。副本不覆盖同名文件或已打开的会话，成功保存副本后才释放旧草稿。
- 比较窗口固定绑定原会话与路径，关闭后到达的读取结果不会进入新窗口。探测结果同样核对会话身份、版本、挂载代数与操作状态，忽略自己的保存/移动后返回的旧结果。

边界：外部重命名显示为原路径缺失与目录中出现新路径，不根据猜测自动重绑草稿或改写 Markdown 链接。附件预览只按大小、mtime 与类型探测，同大小且保留 mtime 的二进制改写可能不提示；文本使用强哈希。大量打开的标签页可能超过整轮检查时间，性能改进留待 M3 实测；暂停中的保存、图片上传和移动会话在后续轮次复查。浏览器检查是提示与恢复机制，最终写入仍必须满足 ETag 条件；既有外部写入竞态边界见 M1。

新增验证：真实临时磁盘同大小同 mtime 改写、实际定时探测、检查失败与重试、外部改写后的脏缓冲区另存、整个目录被移走且首次另存失败后的草稿恢复；单元测试覆盖自己的保存与旧探测响应交错、外部变化后继续输入、重新加载期间输入。使用独立临时工作区，不操作开发预览中的用户文件。

第二节点标准回归：`make build`、`make test` 与 `cd backend && go vet ./...` 均通过；当前为 9 项前端单元测试、18 项浏览器测试、全部 Go 测试。已检查比较窗口截图，文本框使用显式标签关联。本节点未修改容器构建配方，未重复双架构容器验收。
