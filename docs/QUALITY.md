# M3 无障碍与性能检查

> 后续变更：文件运行时已采用标准库优先实现及新的部署权限边界，见 [PORTABILITY.md](PORTABILITY.md)。本页此前的 Linux openat2/UID/硬链接拒绝和镜像验收结果属于对应历史构建，不能直接当作新实现的验证；独立 Python 备份工具仍是 Linux 专用。


`make qa`（或 `cd frontend && npm run test:qa`）先构建 Vite SPA、复制嵌入资源，再启动隔离的 Go 服务。页面来自实际嵌入构建，不使用 Vite 开发服务。数据、账号和浏览器上下文均为临时测试资源；性能夹具只允许写入测试脚本创建的 `folio-e2e-*/workspace`，结束后清理自己的目录。

QA 独立于普通 `make test`，最终回归应运行 **`make test && make qa`**。axe 是固定版本的开发依赖，不进入前端运行时，没有新增产品运行服务。

## 无障碍范围

- Chromium 下浅色/深色 × 1440×900 桌面/390×844 手机视口，共 4 条流程、26 次扫描。包含登录、工作区、富文本、源码、搜索、新建窗口，手机另含模态目录抽屉。
- axe-core WCAG 2 A/AA、2.1 A/AA 检查；保留 violations 和 incomplete，不屏蔽规则或排除编辑器。
- 单独读取 Chromium 真实 AX 树，确认富文本和源码字段的名称、正文值与 Escape/Tab 说明可见。Playwright 局部 ariaSnapshot 会折叠部分 textbox 子项，不能据此把源码字段误判为空；实际 AX 记录另存。
- 键盘覆盖编辑器 Escape→Tab 退出、搜索内循环 Tab/焦点约束、Escape 关闭与回归、新建输入框初始焦点、抽屉到其他窗口的交接、标签 Delete/独立关闭按钮，以及关闭后文件仍存在。原有 workflow/mobile 测试继续覆盖目录键盘操作、触屏、冲突与恢复。
- 修复了可见名称与辅助名称不一致、空 tablist/非法关闭按钮子项、缺少语义角色的模式分组、富文本 Tab 退出、无 Trigger 窗口焦点回归及抽屉抢走新窗口焦点。编辑器补充可见焦点；手机标签与关闭目标增大。

本机证据：`artifacts/qa/accessibility-*.json`、`editor-semantics-*.json` 和四张 `workbench-*.png`。26 次扫描无自动违规。`aria-hidden-focus` incomplete 主要对应 Radix 模态背后的控件/焦点守卫；没有把它当成自动通过，键盘循环与关闭/回归另有断言。当前状态的文本对比度无自动违规，不推断所有动态工具栏、代码语言配色或交互状态均符合 WCAG。

**限制：**这不是完整 WCAG 合规认证。没有在 NVDA、JAWS、VoiceOver、Orca 或真机读屏器中验证朗读、输入法和虚拟光标；AX 树、扫描与键盘测试不能替代这些检查。编辑器 AX 样本为标题与普通段落，不宣称复杂表格、代码块和嵌套列表的全部读屏操作均已验证。其他浏览器、相机和真机软键盘仍按 `M3.md` 限制处理。

## 实测性能与预算

一个目录下 **1202 个文件**：1200 个中英文搜索样本、162508 字节/600 段 Markdown、1060800 字节文本。真实分页加载到最后一项；验证中文唯一查询、50 项截断的全文结果、快开 UI、动态加载编辑器，以及编辑后完整正文精确落盘。

首次测量环境：Linux x64，AMD Ryzen 7 8845HS，16 个可用逻辑处理器；Node 24.21.0、Chromium 155.0.8059.79。回环 HTTP，无 CPU/网络限速。基于首轮实测留出余量设定以下预算，后续原始值在 `artifacts/qa/performance.json`：

| 指标 | 首次实测 | 回归预算 |
| --- | ---: | ---: |
| 200 项首屏 | 188 ms | 1000 ms |
| 后续每页，含 DOM 更新 | 256–614 ms | 1500 ms |
| 名称搜索 API，3 次 | 3.4–6.3 ms | 100 ms |
| 全文搜索 API，3 次 | 10.4–12.3 ms | 100 ms |
| 首次 Markdown 打开 | 1453 ms | 3000 ms |
| 首次 1.06 MB 文本打开 | 1554 ms | 3000 ms |
| 富文本输入至后两帧，3 次 | 33–152 ms | 300 ms |
| 源码输入至后两帧，3 次 | 32–147 ms | 300 ms |
| 实际快开 UI，含防抖 | 328 ms | 1000 ms |

输入耗时含 Playwright 协议、UI 更新与两帧等待，不叫纯 INP；3 个样本不叫 p95。APIRequestContext 搜索时延与浏览器快开 UI 分开记录。首次打开包含动态分块加载，后续输入在同一实例中进行。预算用于这套机器/夹具的明显退化报警，不是跨设备、WAN、慢磁盘或手机 SLA。

文件树保留显式分页，测量未显示必须引入虚拟化；不为测试替换目录/编辑器模型。保留 Crepe 约 1 MB 的构建分块提示，没有调高阈值掩盖。大于编辑上限的文件仍按原规则拒绝编辑并提供下载。

## 依赖核对

新增固定 `@axe-core/playwright` 4.14.0。审计发现 `micromark-extension-math` 间接 KaTeX 0.16.47 告警；检查其 HTML 渲染仍使用新版支持的 renderToString 后，将这条依赖定向对齐到 Crepe 自身使用的 0.19.0。保留 Crepe/remark 版本和禁用数学编辑的产品行为，没有用 `audit fix --force` 降级整个编辑器。

条件与修复版本见 [KaTeX 官方安全公告](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7)。普通 `npm ci` 与本次审计通过（0 已知告警）；这是当时的依赖数据库结果，不是未来无漏洞保证。Markdown 往返与移动流程继续纳入回归。

## 源码保真补充

最终审计发现并修复 CodeMirror 默认 toString 将原始 CRLF/CR 统一成 LF 的缺口。源码编辑保留原有换行及 BOM，混合格式随编辑事务移动并参与撤销/重做；新行使用本次打开时原文的第一个换行格式，没有换行则用 LF。标记只驻留编辑器模型，不进入文件或 React/Zustand；常见统一格式无需逐行标记。异步图片追加同样沿用原格式。

模型测试、实际磁盘字节断言及恢复稿下载/刷新验证独立于视觉 textarea；浏览器显示控件的换行表示不能当作文件字节。当前回归变为 16 项前端单元、31 项常规浏览器测试，生产 QA 仍为 5 条。新产品构建/两架构 HTTPS 容器也加入 BOM/混合换行的编辑、撤销/重做、重启与改密后保真断言。
