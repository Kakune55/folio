## Markdown 往返样本

输入语料：frontend/tests/fixtures/markdown.json；真实浏览器快照：frontend/tests/browser/workbench.spec.ts-snapshots/。历史 14 组样本不代表任意 Markdown 的无损保证，升级依赖必须复核。当前转换出现差异时允许显式预览确认，取消保留原文；不是静默接受规范化。

| 样本 | 已观察的结果与限制 |
| --- | --- |
| 中文标题、强调、行内代码 | 样本往返一致 |
| 相对链接与图片、带语言围栏、Unicode/组合字符 | 样本路径及文本往返一致 |
| 嵌套任务列表 | 列表标记可能由 - 变为 * |
| 表格 | 分隔行规范化 |
| frontmatter | 可能按普通 Markdown 解析 |
| 转义、引用式链接 | 转义变化，引用链接可能展开为行内链接 |
| 多余空行、硬换行 | 空白可能变化 |
| HTML 与注释 | 样本原文一致，不承诺交互或活动预览 |
| 数学公式 | 数学渲染关闭，按普通源码保留 |
| 脚注 | 样本保留，不承诺完整脚注编辑语义 |

## 保留的使用限制

文件/模式切换的撤销历史和光标可能重置；外部重命名不猜测重绑，Markdown 链接不自动改写。未提供段内锚点导航、远程图片加载、多选批量移动、跨页面拖路径或手机触摸拖拽，使用移动菜单替代。

PDF 不提供完整加密文档、复杂字体/大图、XFA、交互表单/注释或读屏体验保证，须保留原件下载；HEIC 等未声明格式可作为附件但不承诺内联预览。

回收站不支持永久清空、到期清理、任意改路径恢复或后台任务队列；原父目录需存在。损坏清单、残缺隔离原件和清理失败副本须人工检查，不自动删除。大子树摘要与跨盘复制耗费空间及 I/O，可能阻塞同实例其他存储操作；不承诺任意超大目录/崩溃阶段已覆盖。

浏览器草稿仅本设备同源缓存，未加密，有提交/驱逐窗口；恢复不包含撤销历史、光标或待上传原件。待确认原件只在页面内存，刷新前应上传或下载。账号过期不得清空内存会话。

Crepe/PDF 的大动态分块提示保留；不以提高阈值隐藏。早期 KaTeX 审计告警已在后续定向依赖修复，历史零告警也不代表未来依赖数据库无漏洞。质量、安全和未验证硬件范围分别见 [质量记录](QUALITY.md)、[安全记录](SECURITY.md)、[跨平台说明](PORTABILITY.md)。
