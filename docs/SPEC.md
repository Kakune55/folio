# 产品规范

## 产品定位

Folio 是轻量、自托管、浏览器优先的 Markdown 与开发文件工作区，面向独立工作区中的多账号使用。
普通目录中的真实文件是正文唯一权威；离开应用后仍可用标准工具编辑、检查和备份。
SQLite 只保存应用元数据和可重建索引，不引入块 ID、专有 Markdown 或数据库权威正文。

本文定义产品能力与用户边界，不记录阶段执行过程或测试结果。
安装与配置见 [README 快速开始](../README.md#快速开始)，界面规则见 [设计规范](DESIGN.md)。
内部机制见 [架构说明](ARCHITECTURE.md)，协议见 [接口说明](API.md) 与 OpenAPI。
当前待办与已知限制见下文，验证方法与环境边界见 [测试计划](TESTPLAN.md)。

## 固定技术

| 层次 | 固定选择 |
| --- | --- |
| 前端 | React、TypeScript、Vite 单页应用 |
| 界面 | Tailwind CSS、语义主题变量、shadcn/ui、Radix、Lucide |
| 路由与状态 | React Router、TanStack Query、Zustand；正文缓冲独立管理 |
| 编辑器 | Milkdown Crepe 富文本与 CodeMirror 6 源码编辑 |
| 后端 | Go 模块化单体、net/http，单进程嵌入前端 |
| 存储 | 本地文件系统与嵌入式 SQLite |

依赖版本以锁文件为准，使用前核对已安装类型与接口；未经明确决定不替换技术栈。

## 当前能力

- Markdown 默认富文本编辑，可切换源码；识别的 UTF-8 文本可用源码编辑器编辑。
- 文件树与标签页支持新建、重命名、移动、上传、下载、回收及恢复；同页同路径共用编辑会话。
- 支持位图、PDF 预览及原件下载；HTML/SVG 仅源码或下载，未知二进制仅元数据与下载。
- 使用标准相对链接和图片路径，支持图片粘贴上传、现有文件拖入引用及站内引用导航；不强制附件目录。
- 支持本地隔离的 Mermaid 预览，单图最多 50000 字符／500 条边；不支持自定义配置、活动 HTML／外部图片或图内交互，错误与超限明确提示，不修改正文。
- 提供中英文名称、路径与已保存文本搜索，以及编辑器内关键词定位；不搜索未保存草稿、PDF 正文或 OCR。
- 搜索索引由应用文件变更更新；宿主直接修改文件后，搜索需手动重建或重启后更新，无周期目录扫描。
- 提供 Markdown 大纲、其他文本缩略导航、快捷键、明暗主题与本机显示偏好；呈现变化不改正文。
- 本机标签记录按账号与工作区恢复路径、顺序及当前标签；正文重新读取，未保存内容另走草稿恢复。
- 提供用户设置、分类存储统计、管理员用户管理、配额、在线限制设置与系统状态。
- 应用 API 提供文件、附件、搜索和回收恢复，以及严格条件 diff 修改、按行读取和渐进式契约发现。

搜索结果沿用已打开会话与草稿，不因定位重载正文；索引与当前内容不同而无法定位时明确提示。
移动文件不自动改写链接；本机偏好和标签记录不跨设备同步，标签记录不承诺恢复模式、光标或滚动。

## 保存与恢复底线

- 更新必须携带原版本条件，不提供无条件覆盖、最后写入者覆盖或自动合并。
- 自动保存与显式保存共用版本保护；请求期间继续输入，不得被旧响应误标为已保存。
- 保存失败保留正文与未保存状态，提供重试、冲突比较或另存不覆盖副本的恢复入口。
- 正文草稿独立于全局界面状态，不因切页、进入设置或逐键输入重建编辑器而丢失。
- 文件或模式切换保留正文；可能重置撤销历史、光标或滚动的操作必须说明限制。
- 源码保留 BOM 与原有换行形式；不把按行读取的片段当成整篇候选覆盖文件。
- 富文本准入以可验证的保源兼容性为准，不能仅凭序列化字节差异要求转换。
- 不编辑就不回写；真正编辑时保留未变块与空白，已编辑的列表、表格、引用等整体容器可能规范化。
- 不承诺所有 Markdown 无损编辑；危险或无法可靠表达的语法进入源码或显式转换确认。
- 转换须展示原文、结果与差异并允许下载原文；取消保留原文，确认不等于创建持久备份。
- 粘贴或拖入无法无损表达的危险 Markdown 原文时，明确阻止插入并提供源码入口，不能静默丢语法。
- 结构歧义、资源不足或无法验证语义时明确拒绝，不用全文序列化兜底覆盖原文。
- 段末 Shift+Enter 当前不支持，必须在输入前说明未生效，不能伪装成成功写入硬换行；段中行为不变。
- 本机恢复稿按账号工作区、路径和独立会话隔离，显式打开为暂停自动保存的源码会话，不覆盖已有脏标签。
- 浏览器缓存有提交窗口、配额和驱逐风险；待确认上传原件仅在页面内存，失败提供下载、重试或确认移除。

只支持单实例写工作区；对不协作的外部写入者不承诺全局文件系统条件交换。
干净会话安全核对后可加载外改，脏会话暂停自动保存并保留草稿；外部重命名不自动推断文件身份。
SSE 通知应用 API 变更，宿主直接写入不触发 SSE；版本轮询与焦点核对提供补偿，不代表搜索已更新。
远程通知对干净的已打开文本先加载最新内容；接受或 10 秒自动接受仅确认保留，不重复写盘。
等待暂停倒计时，连续变化合并且保持等待；本地草稿不被覆盖，通知关联标记随决策清理。
回滚以最新通知版本条件写回本轮初始正文，冲突明确拒绝；保留本地草稿及其暂停自动保存状态。
通知初始正文仅在页面内存，不保证刷新后恢复；删除或非文本不伪造完整统计与回滚能力。
通知来源只是认证事件提示，不是审计记录或精确版本作者；自动重载可能重置撤销历史。
回收站、恢复缓存和通知都不是备份；文件卷与 app-data 卷只是持久存储，双卷本身不是备份。
服务器备份与恢复必须停写并成对处理两卷，不能只复制正文而遗漏账号、分享和元数据。

## 安全、分享与账号边界

- 关闭公开注册，首个初始化账号为管理员；管理员可管理用户和配额，但无浏览其他用户正文的入口。
- 账号使用稳定身份隔离目录、搜索、回收站、草稿与分享；改名或改密不改变工作区归属。
- 退出或账号切换须处理未保存正文和待上传原件；旧页面身份变化后停止旧工作区写入并保留正文下载入口。
- 密码哈希、可撤销会话、来源与 CSRF 校验、登录限速保护账号；离线恢复不提供匿名远程重置入口。
- 工作区读取、搜索、下载和预览均需认证；公开分享另有独立授权，登录不绕过分享密码或访问资格。
- 路径限定在工作区内，拒绝穿越、静态符号链接和特殊文件；上传执行流式限制，同名不覆盖。
- 运行用户、权限/ACL、硬链接与嵌套挂载由部署者管理；恶意同用户进程与并发目录替换不在隔离保证内。
- 配额是应用管理的逻辑用量，不是宿主硬配额；正文、附件、回收载荷与分享快照计入，外部写入不由应用拦截。
- 降低配额不删除文件；移入回收站不释放配额，临时写入和快照替换仍需额外空间；统计失败拒绝增长写入。
- 分享支持实时或快照、密码、到期、次数、暂停与删除；实时仅一个主文件，含任何附件都必须快照。
- 每包最多 256 文件／128 MiB，每账号最多 1000 条分享；到期记录由后台清理，暂停／次数用尽不自动释放快照，清理失败保留检查入口。
- 实时分享只读取原工作区身份和路径的已保存内容，不自动包含引用；原路径复用可能展示新文件，须明确告知。
- 快照保存主文件与显式确认附件的原始字节，计入分享者配额，不随来源修改；发布前版本变化拒绝陈旧确认。
- 分享权限独立于工作区，访客只能读取确认范围；暂停、过期、禁用或版本变化拒绝后续访问，已下载内容无法收回。
- 访问次数不是独立人数；公开页无目录浏览、匿名上传或远程抓取，HTML/SVG 与附件不执行、不解压。
- 转存要求有效登录及分享访问资格，生成独立副本，遵循接收者限制与配额，同名不覆盖、不部分发布。
- Access Token 按文件、搜索、回收站授权，作用于本账号整个工作区，不支持目录级授权；完整令牌仅生成时可见。
- Token 不能登录浏览器、改密、管理账号/系统/令牌、私有分享管理或转存，也不能永久删除回收站文件。
- Token 不放宽条件写、路径、配额或上传限制；改密、重置、禁用及备份恢复按既有规则撤销，已开始请求可能完成。

## 已知限制与待办

- 编辑器保源仍在完善：继续核对常见输入、复杂列表／表格／引用、空段与硬换行、撤销及外改重载行为。无法可靠表达的语法、身份歧义与资源不足继续明确拒绝或进入源码／转换确认，不承诺所有 Markdown 无损，也不以静默丢失或全文回写消除兼容问题。
- 段末 `Shift+Enter` 明确不支持；不得用伪装成功或静默丢弃 hardbreak 掩盖，段中硬换行保持可用。
- 搜索性能：需在既定样本下复核搜索、编辑器输入与切换并分别记录。历史上 1202 文件样本的搜索 API 曾为 315–322ms、Windows 样本约 168–171ms，均高于既有 100ms 门槛，仍待定位；该测量在打开编辑器前，不能作为编辑器性能结论。存在未通过项时不得称完整 QA 全绿。
- 环境验证：真实 HTTPS 代理的 SSE 缓冲／重连／轮询补偿、其他浏览器与真实读屏器、真实移动设备的相机／IME／选区、Windows 与 NTFS 的持久性差异、原生 ARM／Docker daemon／当前镜像与双卷恢复，均待专项验证，不以仿真或旧构建结果代替。

## 不支持与非目标

不支持账号删除、角色调整、旧单账号结构自动迁移，也不把管理员身份等同于跨用户正文访问权。
不支持协作文件夹、文件夹整体分享、任意粘贴文本创建分享或多人实时协作；Windows 持久性不等同 Linux 保证。
不引入块数据库、知识图谱、强制标签、双向链接、插件市场、Obsidian 插件兼容或 AI 写作。
不提供终端、远程执行、Git 界面、离线同步、强制 PWA、S3/WebDAV、多服务或 Serverless 改写。
不提供 OAuth、MCP、可执行 Skill、第三方应用注册、多文件事务或自动合并；公开 API 文档不扩展任务授权。
