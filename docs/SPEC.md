# 产品规范

Folio 是轻量、自托管、浏览器优先的 Markdown 与开发文件工作区。普通目录中的真实文件是产品的核心，离开应用后仍可用标准工具编辑、检查和备份。

## 范围与技术选择

面向自托管多账号：每个用户登录后在独立工作区编辑笔记和配置，将图片、PDF、日志及归档与笔记放在同一目录，通过文件树和统一搜索定位内容。部署为嵌入前端的 Go 单进程、单容器，使用 workspace 与 app-data 两个独立持久目录。

| 层次 | 固定选择 |
| --- | --- |
| 前端 | React、TypeScript、Vite 单页应用 |
| 界面 | Tailwind CSS、语义主题变量、shadcn/ui 与 Radix、Lucide |
| 路由与状态 | React Router、TanStack Query、Zustand；正文独立管理 |
| 编辑器 | 动态加载 Milkdown Crepe 与 CodeMirror 6 |
| 后端 | Go 模块化单体、net/http |
| 元数据与索引 | 嵌入式 SQLite；账号 app.db 与可重建 search.db 分离 |
| 正文权威 | 本地文件系统，不在数据库中保存权威正文 |

依赖版本以锁文件为准，使用前核对已安装类型与接口。桌面拖拽目前使用原生事件，不要求另引入拖拽库。

## 文件与编辑

- Markdown 默认富文本编辑，可切换源码；识别的 UTF-8 文本由 CodeMirror 编辑。
- PNG/JPEG/WebP/GIF 可预览；PDF 使用 PDF.js 画布预览并保留原件下载。SVG/HTML 仅源码或下载，未知二进制仅元数据与下载；不解压、不执行附件。
- 文件树支持新建、重命名、移动、上传、下载、移入回收站及恢复；不强制附件目录。单页同一路径只保留一个编辑会话。
- 使用标准相对链接与图片路径，不引入专有语法。站内文件在标签页打开，外链隔离打开，远程图片默认不联网；移动文件不自动改写链接。
- 文件和模式切换保留正文；撤销历史与光标可能重置，必须提示。源码保留 BOM、LF/CRLF/CR 与混合换行，新行采用打开时的首个换行格式，无换行则用 LF。

富文本转换必须实际解析并序列化比较。发现差异时展示原文、转换结果和可展开差异，支持下载原文；取消、Escape 或关闭预览均保留原文并进入源码。仅明确确认才替换会话正文，之后仍遵循条件自动保存；确认不会创建持久备份。预览期间正文变化或会话锁定时拒绝旧结果。兼容样本与历史限制可在 Git 历史查阅。

## 保存与恢复

读取返回不透明版本；更新必须携带 If-Match，冲突不得采用最后写入者覆盖。约 800ms 停顿后自动保存，显式保存可立即提交；请求中继续输入不得被旧响应误标为已保存。同目录临时写入、同步、复核版本后替换，失败保留草稿。具体协议见 [接口说明](API.md)。

服务器只支持单实例写工作区。外部正文编辑通过周期核对和 ETag 检测；不提供对不协作外部写入者的全局文件系统条件交换保证。干净会话提示显式加载，脏会话暂停自动保存并比较或另存不覆盖副本，外部重命名不自动推断身份。

浏览器本机恢复缓存按工作区、路径和独立会话隔离。恢复必须显式打开为暂停自动保存的源码会话，不能覆盖已有脏标签。缓存有提交窗口、配额与驱逐风险，不是备份；待确认上传原件只保存在页面内存。服务器备份必须停写并成对处理两卷。删除进入回收站，回收站也不是版本历史或备份。

## 搜索与操作

统一搜索同时查询名称/路径与已保存文本正文，支持中文和英文，不搜索未保存草稿、PDF 正文或 OCR。索引默认正文上限 5 MiB，超限及二进制仅索引名称；索引错误不能阻止编辑。API 文件变更驱动异步增量更新，无周期目录扫描；启动首次访问工作区和手动重建全量核对。直接修改宿主目录需手动重建或重启后更新搜索。刷新实现见架构说明，限额配置见 README。

快捷键：Ctrl/Cmd+S 保存，Ctrl/Cmd+P 或 Ctrl/Cmd+Shift+F 打开统一搜索，编辑区外 Ctrl/Cmd+B 切换目录；Ctrl/Cmd+Alt+W 保存并关闭工作区标签，Alt+PageUp/PageDown 切换。保留浏览器自有关闭/切页键和编辑器加粗键，并提供可见菜单替代。

## 安全与部署

本地多账号，首个初始化账号 admin 为管理员，关闭公开注册；管理员创建用户、修改用户名、启用/禁用、调整磁盘配额与重置密码，用户凭原密码自助改密。管理员不提供浏览其他用户正文的入口，暂不支持账号删除或角色调整。Argon2id 密码哈希、可撤销会话、HttpOnly/Secure/SameSite Cookie、来源与 CSRF 校验、登录限速。工作区文件、下载、预览和搜索均需账号认证；用户明确创建的分享通过独立访问授权提供只读公开入口。离线改密必须停服，用同一二进制更新密码并在事务内撤销会话，不提供匿名远程重置入口；在线管理员重置仅作用于指定用户，离线命令恢复首个管理员并撤销全部会话。

路径必须限定于工作区，拒绝穿越、静态符号链接和特殊文件；使用 Go os.Root。运行用户、目录权限/ACL、硬链接与嵌套挂载由部署者管理；恶意同用户进程和并发目录命名空间替换不在应用隔离保证内。Windows 和 Linux 持久性保证不同。

上传与文本限制以启动配置初始化，管理员保存的系统设置可在线覆盖，流式执行，不信任 Content-Length；同名不覆盖。默认文本 5 MiB、图片 20 MiB、PDF 50 MiB、其他附件 100 MiB、图片 3200 万像素。部署支持直接 TLS 或既有 HTTPS 代理，不增加代理服务。

## 不属于 V1 的功能

块数据库、知识图谱、强制标签、双向链接、插件市场、协作/CRDT、终端或远程执行、Git 界面、AI 写作、Obsidian 插件兼容、离线同步、强制 PWA、S3/WebDAV。

验收要求与可复现命令统一见 [测试计划](TESTPLAN.md)；不能用历史镜像结果证明新构建。

## 多账号与配额

账号使用不可变数字 ID，真实文件位于 workspace/<用户ID>/；搜索与回收站在 app-data/<用户ID>/ 下。改名和改密不改变目录及恢复命名空间。会话、目录、正文、附件、预览/下载、搜索、回收站均按服务端登录用户选择资源。浏览器恢复稿按用户工作区身份过滤；退出登录先保存全部正文、处理待上传原件，再整页重载，避免缓存串账号。其他账号在旧页面登录时停止旧工作区写入，保留正文下载入口。

用户默认配额 5 GB，管理员可设 0–1024 TB（内部保存字节，界面按 1024 换算并显示 MB/GB 等）。正文、附件及回收站载荷计入，数据库、索引、回收清单和普通写入临时文件不计入。故障隔离原件与遗留回收载荷仍计费。配额是应用管理的持久文件逻辑用量，不是宿主文件系统硬配额；临时写入需要额外可用空间，外部工具写入不由应用拦截。

新增、正文增长和上传在存储锁内检查；上传同时有流式限制及提交前复核。降低配额不删除文件，超额后允许读取、下载、缩小正文、回收/恢复及永久删除完整回收记录。移入回收站不释放配额；恢复只是移动已计费用量。统计失败明确报错，禁止增长写入。永久删除需要确认，损坏/未完成回收记录不提供永久删除按钮。

开发阶段不提供旧单账号结构迁移；应停服后清理两数据目录重新初始化，程序不会自动删除旧数据。

正文索引按内容识别 UTF-8 文本，不以 Markdown 或扩展名白名单限定：支持 TXT、LOG、JSON、YAML、TOML、INI、CSV、源码、HTML/SVG 源码及无扩展名文本。非 UTF-8、含 NUL、PDF、位图或超出正文索引限额的文件只索引名称/路径；不执行 HTML/SVG，不提取附件正文。

搜索结果打开文本文件后，在当前编辑器中定位并选中关键词首次出现的位置；已打开的文件继续使用现有会话与草稿，不因定位重载正文。仅名称命中正常打开；索引结果与当前内容不同导致无法定位时明确提示。Markdown 富文本使用文档位置定位可见文字，源码使用自身文本坐标，不把磁盘偏移直接套用到草稿。

标签页右键菜单提供关闭、关闭其他、关闭右侧标签页、关闭已保存、关闭所有；作用范围以被右键的标签及当前显示顺序确定。批量关闭沿用保存与上传/冲突保护，失败文件保留标签和正文；关闭不删除磁盘文件。关闭已保存不触发脏文件保存，仅关闭仍处于干净已保存状态的会话。


## 系统设置与状态（2026-10-17）

管理员系统管理增加用户管理、系统设置、系统状态三个页面。系统设置可调整文本/图片/PDF/附件字节上限、图片像素上限与正文索引上限，持久保存并在线生效；索引变化异步全量重建，已有正文不删除。运行状态展示 Go 运行时与 GC 指标；磁盘目录用量由管理员显式统计。

## 右侧文档导航（2026-10-17）

主题与快捷键按钮之间提供可展开/收起的文档导航，默认收起。Markdown 富文本和源码均生成分层标题大纲，支持点击定位重复标题；无标题时显示空状态。其他可编辑 UTF-8 文本使用可点击定位的抽象线条缩略图（保留缩进和长度轮廓，不显示迷你文字），显示当前可视区域，支持按住视窗拖动连续滚动、点击轨道定位，以及方向键与 Home/End。拖动只改变滚动位置，不改写正文或重设编辑光标。图片、PDF 与二进制不提供此导航。导航基于当前编辑缓冲，不读取旧磁盘正文、不写入正文元数据、不改变自动保存协议。


## 个性化（2026-10-19）

顶栏快捷键前增加个性化模态框。Markdown 富文本正文宽度为 800 / 1200 / 1600px，默认 1200px，可用空间不足时收缩；小于 768px 时不应用宽度限制。编辑器字号为 14 / 16 / 18px，默认 16px，手机最小 16px；适用于富文本与源码。提供恢复默认。偏好仅保存在当前浏览器 localStorage（跨账号共用、不跨设备同步），读取/保存失败明确提示并可重新选择重试。仅通过 CSS 变量改变呈现，不重建 Crepe/CodeMirror，不修改正文、ETag 或恢复机制。手机上传入口保留在文件抽屉，极窄屏品牌缩为字标，保持顶栏操作可用。


## 彩色差异视图（2026-10-19）

冲突比较（磁盘版本 → 本地草稿）与富文本转换（原文 → 转换后）提供统一彩色行差异、行号、增删统计与换行类型。只用于比较，不提供自动合并或逐块采纳；现有条件保存、显式转换确认与不覆盖副本保护不变。匹配预算超过 250000 个矩阵单元时明确提示按替换区间显示；可视差异超过 2000 行时明确提示截断，完整内容仍在上方正文中可查阅。


## 图片插入与引用导航（2026-10-19）

Markdown 富文本与源码支持粘贴／拖入图片，上传到笔记所在目录，成功后在对应位置插入标准相对路径图片引用。上传期间切换模式／文件仍把引用保留在原笔记；失败原件保留在页面内存，可下载、重试或确认移除。重试使用用户选择的当前目录，成功后将相对引用追加到原笔记末尾；原会话已关闭或锁定则明确提示上传路径，供手动插入。Ctrl+点击（Mac 可用 Cmd）内部文字链接或图片引用在工作区标签打开目标，普通点击保留编辑；外部 HTTP(S) 沿用隔离新窗口，其他协议拒绝。


## 侧栏拖入引用（2026-10-19）

侧栏现有文件拖入 Markdown 正文会在落点插入相对引用：PNG/JPEG/WebP/GIF 扩展名插入图片，其他文件插入文字链接；适用于富文本与源码，不移动、不重新上传原文件。目录暂不支持插入引用，明确提示。文件拖到目录仍沿用原有移动行为。


## Mermaid 代码块（2026-10-19）

Markdown 富文本中的标准 `mermaid` 围栏代码块支持图表预览，保留同一代码块的源码与编辑／预览切换；语言菜单可选择 mermaid。源码模式继续编辑原始 Markdown。预览不修改正文、ETag、脏状态或恢复缓存；语法错误、资源加载失败与超限明确显示原因，编辑代码后重试。主题切换重画图表，不重建编辑器。

渲染按需加载本地打包 Mermaid 12.2.0，无远程图表服务。单图上限 50000 字符，Mermaid 边数上限 500；为保持本地预览隔离，拒绝配置指令／frontmatter、HTML 标签、图片／图标属性、自定义 style/classDef/linkStyle 和 click 命令。图表作为非活动 SVG 图片展示，不执行图内链接或脚本。复杂图表仍可能阻塞浏览器，未承诺执行时间上限。


## Mermaid 渲染防抖（2026-10-19）

Mermaid 连续编辑按代码块独立防抖，停顿 600ms 后渲染最终代码。等待和渲染期间显示上次成功图表并标记待更新，新图加载完成后替换；首次打开显示准备提示。错误不清空已有图表，保留错误说明并明确旧图不代表当前代码。


## 本机标签恢复（2026-10-22）

刷新或重新登录后，按当前账号与工作区恢复本浏览器的文件标签列表、顺序及当前标签。localStorage 仅保存路径与选中项，正文仍重新读取服务器；未保存内容须从浏览器恢复稿显式恢复。读取失败保留待恢复路径并显示重试，用户可选择“仅记住当前标签”重置标签记录，不删除草稿。清除站点数据会丢失记录，不支持跨设备同步、编辑模式、光标或滚动位置恢复。同账号多个页面不实时同步，以最后成功保存的标签记录为准。

## M5 分享（2026-10-22，用户授权）

右上角“分享管理”进入 /shares，维护当前用户的分享，返回工作区保持原编辑器与正文。当前文件工具栏提供“创建分享”，直接对当前文件创建外部链接，成功后就地复制；管理页也可输入工作区内任意普通文件路径创建分享。到期时间、密码、访问次数分别由开关启用，关闭时不施加该项限制。支持标题、快照／实时、到期时间、最大进入次数、可选六位数字密码、更新、暂停和删除。六位密码保留前导零，保存 Argon2id 哈希，支持客户端随机生成。每个用户最多 1000 条记录；单包最多 256 个文件、128 MiB。

暂停／继续沿用原链接、密码、有效期、访问上限与已用次数；暂停时拒绝后续访问，继续后仍受过期和次数限制。切换状态使旧访问资格失效，访客须重新进入。删除永久移除记录和快照。

**按用户后续决定：实时模式只允许一个主文件，只要含附件就必须快照。** 实时分享不自动包含任何引用，不能通过修改设置扩充附件；需要附件时创建快照分享。实时绑定来源工作区身份和原相对路径，按已保存内容读取；页面可见时每 10 秒核对大小／mtime，焦点恢复及“刷新内容”也可重读，无协作、推送或编辑入口。外部同大小／同 mtime 修改可能需手动刷新。原路径移动／删除则读取失败；同一工作区内原路径被新文件复用，会显示新内容，创建时明确说明。来源工作区身份变化则实时分享失效。

快照保留主文件及确认清单的原始字节，不受后续原文件编辑／删除影响。载荷存入 app-data/shares/<用户ID>/ 下的普通文件并计入该用户配额，SQLite 不保存正文；更新快照沿用链接并保留已用次数，需要重新分析、核对并确认清单。发布前原文件版本变化拒绝创建，不能悄悄采用陈旧确认。新旧快照切换期间需要容纳完整新包的额外配额。到期后自动删除分享记录、访问资格和快照并释放空间；启动时及每 30 秒清理，管理列表读取时同时清理当前账号的到期记录。单轮最多 1000 条，积压分轮清理。暂停和次数用完本身不触发删除。清理失败明确报错或记录日志，并保留记录供自动重试。到期后不可通过旧管理页面续期恢复。

Markdown 可选择递归分析标准文字链接、图片及引用式链接，只收集同一用户工作区内的本地文件。../ 不得越根；根相对 / 引用从工作区根解释。代码里的伪链接、原始 HTML 中的资源、外部网址／远程图片、目录不会被打包；循环引用去重。通过“选择附件”二级模态框展示完整候选清单，可取消附件，确认后应用到创建弹窗；取消不改变原选择；无法包含的引用逐项警告；超过整个包上限时直接失败，不截断清单。收集范围只在显式分析时改变，未选文件无法通过公开接口读取。

新分享链接为 /s/<16字符Base64URL随机标识>，旧 48 字符链接保持兼容。公开页面不提供工作区目录浏览。成功提交“进入分享”才增加次数，普通打开、密码错误、图片、PDF Range、下载、转存不计次。同一浏览器在同一分享 30 分钟访问资格内刷新／再次进入不增加次数；其他浏览器独立计次，不等同独立人数。最后一次发放串行并在 SQLite 事务中提交，重启保留计数及未过期授权。已有资格可在次数用完后继续使用至资格到期；到期、暂停、分享者禁用及设置／内容版本变化会拒绝后续请求，已传输和已下载内容无法收回。修改分享设置／快照保留已用次数，但要求访客重新进入。

访问密码每分享／直接连接 IP 连续错误 5 次后暂停 10 分钟；不信任任意转发 IP 请求头。高成本密码验证串行，载荷操作最多两个并发、16 个等候（最长 3 秒），超限明确 429 重试。入口不暴露正文和文件清单；密码、来源校验、访问资格验证在后端执行，普通登录不会绕过分享密码。分享管理仅分享者可操作。

公开页提供 Markdown（CommonMark/GFM）、UTF-8 文本、位图及 PDF 只读预览，其他文件仅原件下载。Markdown 原始 HTML 不活动展示，远程图片不联网，Mermaid 沿用本地图片隔离和既有大小／语法限制；富文本不支持的语法可用“查看源码”或下载核对。HTML/SVG 仅文本或下载，Office／压缩包不转换、不执行、不解压。

“保存到我的工作区”检测同站点有效账号后启用，匿名可登录并返回分享。转存还必须持有分享访问资格及接收账号 CSRF／工作区身份。主文件转存整份确认包，单独选中附件时只转存该文件。默认新建独立目录，保留包内工作区路径布局；根相对 Markdown 引用在副本中改为标准相对路径，其余正文保留，单独转存 Markdown 附件不附带未选文件。目标同名不覆盖，接收者配额与文件限制检查失败时不发布部分目录；持久性不确定须核对目录，不盲目重试。副本独立于分享的更新、暂停与删除。

不加入协作文件夹／工作区、公开注册、文件夹整体分享、任意文本粘贴创建、匿名上传或远程资源抓取。协作仅作为后续讨论方向，未授权实施。

转存根相对引用只修改解析器确认的 URL 字节区间，不替换普通文字、转义文本或代码中的相同字符串。极复杂的引用定义若无法安全定位，明确拒绝转存并保留原件，可先改成相对引用后重新创建快照或下载原文件。

## M6 用户设置与 API 访问令牌（2026-10-26，用户授权）

/user-setting 提供账号、存储、应用三个栏目。工作区左下角原系统设置位置改为用户设置；管理员系统设置移至用户设置顶栏，原 /system-setting 路由保留。进入两种设置及返回均保留正文会话和编辑器。账号栏目复用原密码验证的自助改密；成功后撤销全部会话及访问令牌，提示重新登录，保留当前页正文。

存储栏目按需统计当前账号已保存文件，以分段用量条和列表显示文档、图片、音视频、其他文件、回收站和分享快照；文件分类只依据扩展名，不代表内容识别或预览支持。统计口径与配额一致，普通写入临时文件不计入，故障隔离原件计入其他文件；数据库和搜索索引不计入。不扫描未保存草稿，不提供自动清理。失败明确提示并可重试；不承诺对宿主外部写入的一致快照。

应用栏目管理 Access Token，名称 1–80 字符，每账号最多 100 个（含过期记录），有效期 30／90／365 天或永久。完整随机令牌只在生成响应与当前页面内存显示，可复制或手动选择，离开后无法取回；列表显示前缀、创建、最近使用、到期时间和权限，删除需确认。请求中断时应刷新列表核对，无法取回的令牌删除后重新生成。

授权按文件、搜索、回收站分别选择无权限／只读／读写，默认文件与搜索只读、回收站无权限，至少授予一项。权限覆盖本账号整个工作区，暂不支持目录级授权；回收／恢复另需文件读写。令牌不能登录浏览器、修改密码、管理令牌、管理系统或账号、访问私有分享管理／转存，也不能永久删除回收站文件。改密、管理员重置或禁用账号撤销该用户全部令牌，重新启用不恢复；离线改密和备份恢复撤销全部令牌。已开始的请求可能完成。

HTTP 客户端使用 Authorization: Bearer，保留既有条件更新、文件安全、配额、流式上限和索引通知。令牌绑定创建时的工作区身份，根身份变化后需重新生成。此阶段不实现 MCP、OAuth、第三方应用注册或 Skill。


## 应用 API 接入完善（2026-10-26）

应用页增加 API 文档入口，打开 /api-docs 时保持工作区挂载。文档按接入、文件、附件、搜索、回收站、存储分组，可按路径／方法／功能筛选并展开参数、请求、响应和数据结构；不提供会执行文件操作的在线调试器。加载失败可重试，顶栏沿用统一设置组件。机器客户端可匿名获取不含真实资源的静态 /api/v1/openapi.json。
